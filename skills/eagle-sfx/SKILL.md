# Eagle 音效

用户的 Eagle 素材库里有一包「董北 音效」，14,600 多个，312 个文件夹，9.5 GB。这个 skill 管整包。对 Eagle 只读：不打标签、不移动、不改名。

| 大类 | 数量 | 有什么 |
|---|---|---|
| 转场 | 105 | 嗖声、飞过、蓄势（反向上升、power up）、尖啸。英文名，已全部量好峰值 |
| 撞击 | 126 | 重击、玻璃、钟鼓、激光、掉落、裂响、断电、爆炸、吉他。英文名，已全部量好峰值 |
| 音效 | 13,387 | 生活类 3,230、人 1,451、其他类 1,395、实用类 1,033、战争类 728、运动类 706、动物类 659、交通类 456、高品质汽车 349、办公、工业、恐怖、卡通、武器、脚步、流水、毁坏…… |
| 环境音效大全 | 939 | 自然类 606（风、雨、雷、水、林、火、太空）、多种环境声 188、各种天气 97、BBC 48 |
| BD-FX、iPhone 音效 | 97 | 办公环境、电梯、相机、心跳、打击乐；iPhone 的界面提示音 |

三件事要先知道：

- **四分之三的文件还在 iCloud 上，没下载到本机**。列出来的行尾带 ☁ 的就是。量峰值、导出时脚本会自动下载，一个小文件两三秒。不要为了「先都准备好」去整包下载。
- **峰值是用到时才量的**。转场、撞击两组已经量好；别的在 `export` 时自动量，`list` / `search` 加 `--measure` 也会量当前列出来的那几个。
- **文件名有三种**：英文描述（Glass break 01）、中文（敲击键盘）、编号（01108_SFX）。编号的那三千多个只能靠所在的文件夹找，所以搜索是名字和文件夹名一起搜的。

## 找音效

脚本是本 skill 的 `scripts/eagle_sfx.py`，只用标准库和 ffmpeg。Eagle 要开着（本机接口 `http://localhost:41595`），不需要任何 Eagle 插件。

**先看有什么文件夹**：

```bash
python3 scripts/eagle_sfx.py folders              # 前三层文件夹和数量
python3 scripts/eagle_sfx.py folders 脚步          # 只看路径里带「脚步」的文件夹
```

**按文件夹筛**（`list` 至少给一个条件，整包不能一把列出来）：

```bash
python3 scripts/eagle_sfx.py list --folder 转场 --kind 嗖声 --max 1.5   # 一秒半以内的转场嗖声
python3 scripts/eagle_sfx.py list --folder 各种脚步声 --max 2 --measure   # 两秒以内的单步脚步声，顺手量峰值
python3 scripts/eagle_sfx.py list --folder 转场 --shape 上升             # 铺垫一秒以上才到顶的
```

`--folder` 给完整路径（「转场」「音效 / 人 / 脚步」）就只看那个文件夹和它下面的；给一个词（「脚步」）就看所有路径里带这个词的。`--kind` 是按英文文件名分的类（嗖声、飞过、蓄势、尖啸、重击、玻璃、激光、断电、爆炸、钟鼓、掉落、火、冰、水、电子、暗黑、金属、空灵、拖尾），只对英文名的音效有用，主要是转场和撞击；中文类别直接用文件夹。

**按关键词搜**：

```bash
python3 scripts/eagle_sfx.py search "键盘 OR 打字 OR typing"       # 几个说法一起搜
python3 scripts/eagle_sfx.py search "脚步 -雪 -沙" --max 3          # 减号排除，再按时长筛
python3 scripts/eagle_sfx.py search '"glass break" OR 玻璃'        # 引号里的当一个词
```

名字里就有这个词的排在前面，只是文件夹名对上的排在后面。中文、英文都试一下，两种命名都有。

**按意思搜**（不知道这包里管它叫什么的时候）：

```bash
python3 scripts/eagle_sfx.py search --ai "快速的嗖声" --limit 10
```

这一条要 Eagle 里同时开着「MCP Server」和「AI Search」两个插件，没开脚本会直接说明。它比的是名字的含义，不是声音本身：短词组准，长句子散，编号名的文件认不出，也有搜漏的时候。是关键词搜索的补充，不是替代。

**每行的几个数**：

- **响 / 长**：量过的显示「响」，是听得见的那一段有多长；没量过的显示「长」，是文件时长，后面可能拖着静音。`--min` / `--max` 按这个数筛。
- **峰值**：最响的那一下在文件的第几秒。对齐剪辑点靠它。
- **形状**：`打击` = 一下就到顶；`掠过` = 起来、过去；`上升` = 铺垫一秒以上才到顶。
- **dB**：峰值那一刻的电平。几个音效一起用时拿它估音量，-20 dB 以下的偏轻，要提一点。

分类和名字都可能不准。拿不准就一次导出两三个候选，用 `afplay <文件>` 放给用户听，让他挑。

## 怎么挑

先想清楚这一下在画面里对应什么动作，再按动作找：

| 画面 | 找什么 | 峰值对在哪 |
|---|---|---|
| 硬切、快速滑动、卡片飞入 | 转场里 `--max 1.5` 的嗖声 | 切换的那一帧 |
| 大标题砸下来、数字定格、Logo 落定 | 撞击里的重击，`--max 1.2` | 落定的那一帧 |
| 揭晓之前的铺垫 | 转场里形状上升的（Reverse riser、Bell reverse、Freeze） | 揭晓的那一帧，揭晓处再叠一个重击 |
| 东西飞过镜头、镜头穿过去 | 转场里的飞过 | 物体离镜头最近的那一帧 |
| 结尾收束、画面熄灭 | 撞击里的断电（Power down） | 开始变暗的那一帧 |
| 出错、打碎、打断 | 玻璃、裂响，或「各种毁坏声」 | 碎的那一帧 |
| 画面里真有动作：打字、点击、翻页、关门、走路 | 搜对应的拟音，挑 3 秒以内的单次声音 | 动作发生的那一帧 |
| 场景铺底：办公室、街上、下雨、森林 | 环境音效大全，或搜场景词，挑 15 秒以上的 | 不用对点，淡入淡出 |

质感跟着片子的气质走：科技和界面类用电子、空灵；拼贴、撕纸这类手工感的片子用干净的短嗖声和掉落、纸张类的声音，别用激光和暗黑。同一支片子里的转场声控制在两三种，连着出现的换着用，音量一次比一次低一点。

环境声和长的拟音（几十秒的键盘声、雨声）一般只取其中一段：导出后按 `sfx.json` 里的起止挑一段干净的，在工程里用 `startFrom` / `endAt` 截。

## 用进工程

```bash
python3 scripts/eagle_sfx.py export <id> <id> --to public/sfx
```

把音效拷进项目，并在那个目录里写两份东西：`sfx.json` 记每个文件的峰值、起止、电平，`CREDITS.md` 记原名和所在文件夹。文件名改成小写连字符；中文名和纯编号的用 `sfx-条目号后六位`。还在 iCloud 上的会先下载。不要直接引用 Eagle 库里的路径：路径里有空格和中文，文件也可能还没下载。

**把峰值钉在目标帧上**。音效从 `目标帧 − 峰值秒 × 帧率` 开始放：

```tsx
// Remotion：让 space-woosh.wav（peak 0.73s）最响的一下落在第 90 帧
<Sequence from={Math.round(90 - 0.73 * fps)}>
  <Audio src={staticFile("sfx/space-woosh.wav")} volume={0.6} />
</Sequence>
```

video-shotcraft 的 `SFX[]` 钉帧表是 `{ from, src, volume }`，`from` 按上面的式子算；它自带的 `assets/audio/sfx/` 是免费商用授权的，两边都有合适的时优先用它那份。用 ffmpeg 合成时，延迟毫秒数 = `(目标秒 − 峰值秒) × 1000`，写进 `adelay`。

## 出处和许可

这包音效是课程附赠的合集，里面混着 BBC、影视剧、iPhone 系统音这些来源，原始出处和许可不明，不是 CC0，`export` 写的 `CREDITS.md` 开头会注明这一点。自己看的草稿随便用；要公开发布的片子，用之前告诉用户用了这包里的哪几个，由他决定。需要确定能商用的音效时，用 video-shotcraft 自带的那套。

## 索引

量过的数存在本 skill 的 `index.json`（按 Eagle 的条目号和文件大小记，文件没变就不重量）。某个文件夹经常用，可以一次量完：

```bash
python3 scripts/eagle_sfx.py index --folder "人 / 脚步"
```

它会先说有多少个、要从 iCloud 下载多少 MB。超过几百 MB 的文件夹先问用户，再跑。量不出来的多半是文件没能下载，在 Eagle 里点开它再试。
