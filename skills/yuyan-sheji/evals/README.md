# 评测

- `cases.md`：验收用例：1–7 中英文（阶级区分、盲测、档案会长、语域切换、反刻板、来源清单、变体穿帮），8–14 日语（对象矩阵、内外、现实和二次元分开、盲测、审校、经典类型三层、脚本），15–19（古代身份、时代和语言独立、下意识反应、filler、剧本拷打）。
- `blind/题.md`、`blind/答案.md`（第二轮、第三轮是 `题2.md` / `答案2.md`、`题3.md` / `答案3.md`）：盲测题和答案**分开放**。判卷时只把题和 `examples/` 的档案给判卷人，答案文件不要放进它能读到的目录。
- `runs/`：每轮跑的记录，文件名用日期。

判卷人最好不是写台词的那个会话：用另一个模型（如 `codex exec -s read-only`）或者另开一个会话，只给题和档案。

改了哪一类东西，至少重跑哪几条：

| 改了 | 重跑 |
|---|---|
| 维度参考文件（01–10） | 1、2、5 |
| 原则、来源标记、模板 | 3 |
| 切换相关（03） | 4 |
| `data/variety.tsv` 或脚本 | 7 |
