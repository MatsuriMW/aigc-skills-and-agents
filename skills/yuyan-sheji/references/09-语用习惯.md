# 9 语用习惯

语用是「用话做事」的方式：请求、拒绝、道歉、感谢、打断、沉默。两个人用词水平一样，语用不一样，就是两个人。

---

## 看哪几样

| 行为 | 光谱的两端 | 例 |
|---|---|---|
| 请求 | 直接命令 ↔ 层层客气 | *Pass the salt.* ↔ *I don't suppose you could possibly pass the salt?* |
| 拒绝 | 直说「不」↔ 绕到对方自己明白 | *No.* ↔ *That's an interesting idea. Let me think about it.*（= 不）/ 「这个事情再研究研究」 |
| 道歉 | 从不道歉 ↔ 反射式道歉 | 英国人被人撞了也说 *Sorry*；有的人一辈子不说「对不起」，只用行动补 |
| 感谢 | 不说 ↔ 每件小事都谢 | *Cheers* / *Ta*（英国随便）；「谢了啊」；「客气啥」 |
| 打断和接话 | 抢着说 ↔ 等对方说完 | Deborah Tannen 的「高投入」风格（抢话、重叠说话是热情）和「高体贴」风格（停顿、等待是尊重）：两种人一起说话会互相觉得对方无礼 |
| 沉默 | 怕冷场 ↔ 用沉默当武器 | 不回答就是回答 |
| 赞美和接受赞美 | 直接收下 ↔ 推回去 | 美国人 *Thanks!*；英国人 *Oh, this old thing?*；中国人「哪里哪里」 |
| 批评 | 直说 ↔ 三明治 ↔ 只用反讽 | |
| 话题转移 | 硬转 ↔ 顺着对方的一个词滑走 | |
| 问问题 | 直接问 ↔ 用陈述等对方补 | 律师和警察爱用陈述句当问句：*You were at the bar.* |

## 礼貌的两个方向

Brown 和 Levinson 的礼貌理论分两种：

- **积极礼貌**（拉近）：叫昵称、开玩笑、说「咱们」、夸对方。东北人、美国人、销售常用。
- **消极礼貌**（不打扰）：道歉、限定、给对方留余地、*I'm sorry to bother you, but …*。英国人、日本人、体制内常用。

同一句请求，按两种方向写出来就是两种人。档案里写他默认是哪种，对谁换成另一种。

## 中文语用的几个点

- **客套话不当真**：「改天一起吃饭」「有空来家里坐」。当真的人（外国人、愣头青）就是戏。
- **推辞三次**：给东西、请客、让座，推来推去。
- **称呼抬高**：叫「老板」「老师」「美女」「领导」。
- **面子**：当着外人不驳；拒绝要给台阶。
- **「您看这事儿……」**：把决定权推给对方，实际上已经定了。
