# 2 社会方言和职业语域

社会方言跟着人群走（族裔、阶层、社群），职业语域跟着工作走。两者都**要写规则**，不是一张词表。

---

## 一、黑人英语（AAVE）：写语法，不堆俚语

AAVE（African American Vernacular English）有完整的语法体系，很多规则标准英语里没有对应。写 AAVE 角色时，**先定用哪几条语法规则、什么场合用，再考虑词**。俚语变得最快、最容易写成刻板，是最后才考虑的部分。

### 语法规则（挑 3–5 条写进档案）

| 规则 | 例 | 意思和限制 |
|---|---|---|
| 习惯体 *be* | *She be working late.* | = 她经常加班。对比 *She working late* = 她现在在加班。**不能**用在一次性的事情上 |
| 系动词省略 | *He tired.* *They over there.* | 只在标准英语能缩写（he's、they're）的地方省。*I'm* 一般不省；过去时 *was* 不省；句末不省（*That's who he is*，不说 *That's who he*） |
| 否定一致 | *I don't want nothing.* *Ain't nobody got time.* | 一句里多个否定词互相加强，不抵消 |
| 否定倒装 | *Can't nobody tell him nothing.* *Ain't nobody coming.* | 否定助动词放到句首，强调 |
| *ain't* | *I ain't seen him.* *He ain't here.* *I ain't go.* | 可以替 am not / isn't / haven't，也可以替 didn't |
| 完成体 *done* | *I done told you twice.* | 强调「已经做了」，常带不耐烦 |
| 远过去 *BIN*（重读） | *She BIN married.* | = 她结婚很久了（现在还是）。文字上可以用大写或斜体提示重读，一部剧用一两次就够 |
| *finna* | *I'm finna head out.* | = 正要（来自 fixing to） |
| *steady* | *He steady complaining.* | = 一直不停地（带不满） |
| 愤慨的 *come* | *Don't come in here telling me what to do.* | 带被冒犯的意思 |
| 存在句用 *it* | *It's a lot of folks out there.* | = there are |
| 第三人称单数不加 -s | *She work at the plant.* | 和标准英语的 *works* 交替出现，不是每句都去 |
| 所有格不加 -'s | *my brother car* | |
| *they* 作所有格 | *they house* | |
| 疑问句不倒装 | *Why you ain't call me?* *Where he at?* | |
| 叙事里的 *had* + 过去式 | *So I had went up there and …* | 年轻说话人讲故事时常见，表示一般过去 |

### 写的时候守的规矩

- **密度跟场合走**：同一个人在家、在车间、在教会、在仲裁会上说法不同。很多 AAVE 说话人从小被要求在学校和职场切换成标准英语，这种切换本身就是角色的一部分（写进 `03-语体与切换.md` 的切换表）。
- **不拼错字**：*dat*、*dem*、*wit* 不写；*gonna*、*gotta*、*finna*、*y'all* 这类书面上也常见的可以。
- **俚语写年份**：*on fleek* 是 2014 年前后的，*no cap* 是 2018 年以后的。俚语停在角色二十岁上下那几年，五十岁的人不会追最新的梗。
- **不当潮流词用**：很多被叫作「Z 世代用语」的词出自 AAVE。写非黑人的年轻角色用这些词时，档案里写清楚他从哪学来的（网上、朋友圈子），并和 AAVE 角色的用法区分开：后者有完整语法，前者只有几个词。
- **人先于口音**：角色要有和口音无关的目标、能力、幽默（`principles.md` 第三节）。

## 二、法律英语

律师在法庭、在合同里、在会议上、在家里是四种说法。档案要写他在哪几个场合说话。

| 特征 | 例 | 在哪用 |
|---|---|---|
| 成对 / 成组的同义词 | *null and void*、*cease and desist*、*terms and conditions*、*give, devise and bequeath*、*any and all* | 书面和正式发言；日常说出来是职业病，可以当笑点 |
| *shall* 表义务 | *The tenant shall …* | 合同。口语不用 |
| 古旧的指代词 | *herein*、*thereof*、*aforementioned*、*the said party* | 书面；口语里用就是在摆谱 |
| 名词化 | *the termination of the agreement*（不说 *ending the deal*） | 正式发言、邮件 |
| 被动和去施事 | *Mistakes were made.* *The funds were transferred.* | 回避责任时 |
| 法律拉丁语 | *inter alia*、*prima facie*、*pro bono*、*mens rea*、*voir dire*、*res judicata*、*de minimis*、*sua sponte*、*mutatis mutandis* | 同行之间；对外行说就是压人 |
| 层层限定 | *to the best of my recollection*、*subject to*、*notwithstanding*、*without prejudice* | 不把话说死 |
| 交叉询问句式 | 一连串只能答 yes / no 的短问句：*You were there. At nine. Alone. Correct?* | 法庭；**诉讼律师生活里也这么问人**，很好用 |
| 法庭固定说法 | *Objection, Your Honor.*、*Withdrawn.*、*No further questions.*、*Let the record reflect …* | 法庭 |

**诉讼律师和非诉律师不一样**：诉讼律师短、狠、会表演、会打断；非诉（并购、合规）律师慢、准、限定语多、怕说错。

**边界**：律师的精准不等于用大词。好律师对陪审团说话用最简单的词（*He lied. Twice.*），对同行才用术语。

## 三、其他职业语域（简表）

| 职业 | 对同行 | 对外人 | 典型的话 |
|---|---|---|---|
| 警察 | 代码、缩写、*perp*（偏影视腔）、*vic*、*the suspect*、*vehicle* | 公文腔：*The individual exited the vehicle.* *Ma'am, I need you to step back.* | 报告式的名词化，情绪越大越公事公办 |
| 医生 | 缩写和病名：*BP's crashing*、*bed four*、病人用病名代称 | 刻意平白，加缓冲：*We're going to keep an eye on it.* *There's something I'd like to check.* | 坏消息先垫：*I'm afraid the results …* |
| 学者 | *arguably*、*to some extent*、*nuanced*、*problematize*、*interrogate*、*framework* | 一样，改不掉 | 限定语多；爱说 *Well, it depends what you mean by …* |
| 金融、咨询 | *bandwidth*、*circle back*、*take it offline*、*low-hanging fruit*、*move the needle* | 一样，改不掉 | 被吐槽最多的一类，适合讽刺 |
| 军人 | 短句、命令式、*Copy that*、*Roger*、*Affirmative*（偏影视） | 礼貌形式：*Sir*、*Ma'am* | 情绪最少；退伍多年仍改不掉 |
| 科技公司 | *ship*、*scale*、*iterate*、*ping me*、*sync*、*use case* | 一样 | 年轻、快、名词当动词 |

## 四、中文的方言和社会方言

规则和英文一样：**写词表、语法和语用，不用谐音字拼口音**。方言词每句最多一两个，靠语气和语用立人。

### 京味儿（北京）

| 类别 | 写法 |
|---|---|
| 词 | 甭、得嘞、倍儿、局气（仗义）、瞎掰、犯葛、撒丫子、遛弯儿、颠儿了（走了）、敞亮、有日子没见 |
| 句式 | 「这叫一个……」、「您呐」、「合着……」（原来）、「我跟您说」、反问多 |
| 语用 | 「您」用得多，客气里带讽刺；贫嘴、绕着说、爱抖机灵；老北京讲面儿 |
| 儿化 | 文字上只在已经固定的词里写（遛弯儿、一块儿），不要每个名词都加「儿」 |

### 东北话

| 类别 | 写法 |
|---|---|
| 词 | 嘎哈（干啥）、咋整、整（万能动词）、唠嗑、嘚瑟、埋汰（脏、损人）、磨叽、贼（副词，很）、老鼻子了（很多）、杠杠的、膈应、得劲儿、削（打）、忽悠 |
| 称呼 | 老妹儿、大兄弟、大姐、老铁、老弟、大侄儿 |
| 句式 | 夸张和比喻多；「那家伙」开头接一串描述；「必须的」；反问加强语气（「那还用说？」） |
| 语用 | 自来熟，热情得不给人拒绝的空间；损人是亲近；吵架和开玩笑的界限很近 |
| 慎用 | 「你瞅啥」「瞅你咋地」这类已经成了小品梗的，给一个角色用一次就够，用了要有剧情理由 |

### 粤语夹英文（香港）

- 夹的多是名词、动词和固定说法：*check* 一下、*book* 位、*send* 个 *email*、*present*、*deadline*、*so*、*anyway*、*OK*。
- 写普通话台词时，用「中文句子 + 英文词」表现，粤语字（嘅、咗、唔）只在剧本整体用粤语时才写。
- 阶层：中产和专业人士夹得最多；老一辈和基层夹得少，夹的是旧外来词（的士、巴士、士多）。

### 体制内话语

- 词：原则上、研究研究、高度重视、抓手、落实、推进、统筹、同志、领导、「这个事情」
- 句式：三段式（「一是……二是……三是……」）、先肯定后转折、不说死（「原则上同意」「再研究」）
- 语用：拒绝不说「不」；对上和对下两套语体，切换很快（写进切换表）

### 互联网黑话和大厂话

- 词：对齐、颗粒度、闭环、赋能、抓手、底层逻辑、方法论、打法、复盘、拉通、心智
- **写年份**：2019–2021 年最盛，后来被嘲讽得多。用的人和场合要清楚：真信的、自嘲的、被同化的，说法不同

### 留学生中英夹杂

- 夹的是**概念和固定搭配**，不是随便替换：*deadline*、*presentation*、*project*、*scope*、*basically*、*anyway*、*literally*、*vibe*
- 夹得太多而且词很基础（「我今天 *very* 忙」）是在演留学生，不是留学生。真正夹的是中文里说起来更费劲的词
- 和父母说话时夹得少，和同学说话时夹得多：写进切换表
