# 3 语体和随对象切换

一个人不是只有一种说法。同一个人对老板、对老婆、对陌生人、对警察说话都不一样；**切换的方式本身最能说明他是谁**：谁能让他换档、他换得多快、换不过来时哪里露馅。

---

## Joos 的五种语体

Martin Joos 在 *The Five Clocks*（1962）里把语体分成五档。档案里给每个常见对象定一档，再写这一档在他身上具体长什么样。

| 语体 | 什么时候 | 特征 | 例 |
|---|---|---|---|
| 冻结（frozen） | 仪式、誓词、法律文书、祷词 | 一个字不能改，代代照念 | *Do you solemnly swear …* / 「我宣誓……」 |
| 正式（formal） | 演讲、法庭陈述、对不熟的上级 | 完整句、少缩写、不打断、用词偏书面 | *I would like to raise a concern regarding …* |
| 商议（consultative） | 和陌生人、医生、店员、同事谈事 | 一来一回，有背景说明，有回应词（*right*、*I see*、「嗯」「对」） | *So what you're saying is …* |
| 随便（casual） | 朋友、熟同事 | 省略多、俚语、缩写、不交代背景 | *You coming?* / 「走不走？」 |
| 亲密（intimate） | 伴侣、家人 | 半句话、私人代号、只有两个人懂 | *Again?* / 「又来？」 |

| 对象 | 档位 | 他身上的变化点 | 例句 |

| 下属 / 服务人员 | | | |

| 喜欢的人 | | | |

「变化点」要写具体：哪些词换了、句子长了还是短了、口音变浓还是变淡、称呼怎么变、开不开玩笑。例：

- 底特律修理工（AAVE）对工会仲裁会：系动词补全，*ain't* 换成 *isn't*，句子变长、带数字和日期；一离开会议室就切回来。
- 东北烧烤店老板娘对城管：从「老妹儿」「大兄弟」换成「同志」「领导」，方言词几乎全收，嗓门不变。
- 纽约诉讼律师对十岁的儿子：还是交叉询问的句式（*Did you or did you not …*），只是用词降到小孩的档。这种「换不过来」本身就是性格。

## 语码转换（code-switching）

会两种语言或两种变体的人，在什么时候切过去？

| 触发 | 例 |
|---|---|
| 换了听众 | 对父母说中文，对同学说英文 |
| 换了话题 | 谈工作用英文词，谈家里用方言 |
| 情绪上来了 | 骂人、哭、撒娇时退回母语或方言 |
| 要拉近 | 对同乡、同族突然用方言或社群的说法 |
| 要拉开 / 排外 | 当着外人和自己人说对方听不懂的话 |
| 要压人 | 对服务员突然换成更正式、更标准的说法 |
| 词不够用 | 某个概念只在另一种语言里有现成的词 |

档案里写：**他会哪几套、默认用哪套、什么情况往哪边切、切的时候第一个变的是什么**（往往是称呼和语气词先变，句法最后变）。

## 往上爬的人：两套语码和矫枉过正

出身和现在的阶层不同的人（第一代大学生、底层出身的律师、暴发户），通常有两套语码。

- **在外面用新的那套，用力**：Labov 发现中下阶层在「小心说话」时会比上层更用力地往标准靠，用词会**矫枉过正**：*between you and I*（正确是 *me*）、*whom* 用错地方、把 *myself* 当宾语（*Contact John or myself*）、大词用错（`04-用词水平与精准度.md` 的「用错词」）。
- **压力下退回去**：累了、醉了、对家里人、被羞辱时，出身的那套冒出来。写进档案的「例外登记」。
- **对出身的态度**写进档案：藏、骄傲、还是看场合拿出来当武器。

## 检验用例：吵架换语体

改自 Writers' Greenhouse 的练习：两个人吵架，先按档案写一遍；再把一个人改成很正式、另一个很随便，看人物有没有真的变。**如果只换了几个词、人物关系和情绪没变，说明档案里的语体只写了表面。** 这个练习放在 `../evals/cases.md` 当验收用例。
