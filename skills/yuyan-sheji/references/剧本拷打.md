# 模式 R：剧本阶段的拷打

语言设计不是拍之前给台词润色，而是**在剧本阶段就进来，逼问每个人物和每句台词**。分镜和视频都开始了再改台词，时长、口型、表演全要重来，所以越早越便宜。

**位置**：大纲或初稿 → **R 拷打** → 定稿剧本 + 语言档案 → 分镜（`cinematic-director`）→ 配音（`peiyin`）→ 视频。

**什么时候用**：用户手上有剧本、大纲或一场戏，说「帮我过一下台词」「拷打一下这个剧本」「台词太假」；或者要进分镜之前，主动提一句可以先过一遍。短到只有几句的，只跑第二关。

---

## 规矩

- **一次只问一个问题，并给你的推荐答案**，让用户选或改。有 AskUserQuestion 就用。
- 能从剧本里推出来的不问，自己推，标〔推测〕。用户说「你定」就定。
- 问题要具体：不问「他性格怎么样」，问「他踩到钉子时第一个字是什么？」
- **用具体的句子逼**：每个问题都给 2–3 句候选台词，反应比描述可靠。
- 记下用户的每个反应（「这句像」「太文了」），写进档案，标〔台词〕。
- 用户累了就停，把没问完的列出来。

---

## 第一关：定轴和人

1. **语言 / 时代 / 风格**：中文、英文、日语；现代、古代（朝代）；日语的现实 / 二次元；类型层（`era/00-时代轴.md`、`ja/05a`）。
2. **角色清单和关系表**：谁对谁、上下、亲疏、内外（日语必须）。
3. **逐个人物拷打**（主角 8–10 问，配角 2–3 问）：

| 问 | 拷打什么 |
|---|---|
| 他小时候家里谁说话最多？什么口音？ | 底层语码 |
| 现在和小时候说话一样吗？什么时候变回去？ | 两套语码 |
| 他踩到钉子、撞车、听到坏消息，第一个字是什么？ | 下意识反应（`07a`） |
| 他卡壳时说什么？在想什么时填什么词？ | filler |
| 他开口的第一句通常是什么？结束一段话怎么收？ | 常用表达 |
| 对老板和对妈妈，同一句「我不去」怎么说？ | 切换 |
| 想要钱时怎么开口？拒绝时怎么说？道歉呢？ | 语用 |
| 撒谎时话变多还是变少？ | 情绪和语言 |
| 他绝不会说的一句话是什么？ | 边界 |
| 有什么词他总用错，或者不认识？ | 用词水平 |
| 古代：他怎么称呼自己？对上官、对老婆、对下人？读过书吗？ | 称谓 |
| 日语：俺、僕、私分别对谁？敬语到哪一档？ | 人称、敬语 |

每个人出档案 v1。

---

## 第二关：逐句拷打

一场一场过，每句台词过这张表。不用全问，挑最可疑的。

| 测试 | 问 | 不过时 |
|---|---|---|
| **换人** | 把这句给别的角色，行不行？ | `GENERIC`：拉开一个维度 |
| **念出来** | 真人一口气念得完吗？有地方换气吗？ | 拆开、缩短 |
| **太干净** | 真人这时候会说这么完整吗？ | `TOO_CLEAN`：加半句、改口、filler、脱口词 |
| **第一反应** | 听到大事，第一个字是不是脱口的？ | `NO_REFLEX`：先写反应，再写内容 |
| **说给观众听** | 他们俩都知道的事，为什么要说？ | `INFO_DUMP`：删、改成争吵的前提、挪到画面 |
| **直说** | 真人会这样直说感受吗？ | `ON_THE_NOSE`：换成做事、岔开、说反话 |
| **回应** | 他真的在答对方的话吗？ | 人常常不答所问；抢话、打断、接错 |
| **对象** | 这个称呼和语体对这个人吗？ | 查切换表（日语 `ja/04`） |
| **时代** | 这个词、这个想法，这个时代有吗？ | `ERA_ANACHRONISM`、`ERA_MODERN_MIND` |
| **时长** | 这个镜头放得下吗？ | `ja/07` 的拍数；中文约 4–5 字/秒、英文约 2.5–3 词/秒（估算，要实测） |
| **遮名** | 遮住名字，能认出是谁吗？ | 回档案 |

**让台词变真的手法**（挑着用）：

| 手法 | 例 |
|---|---|
| 说一半 | 我不是…… 算了。 |
| 改口 | 他昨天——不是，前天。 |
| 重复 | 你说什么？你再说一遍？ |
| 不答所问 | ——你吃了吗？——门没锁。 |
| 抢话 | 两个人一起开口，一个停下 |
| 跑题 | 吵架时突然说「你鞋带开了」 |
| 反应先于内容 | 卧槽。……谁告诉你的？ |
| 不说出口 | 该说「我爱你」时说「多穿点」 |
| 用错词 | `04` 的用错词 |

但要留白：**不是每句都要这样**，全是半句话的戏同样假。主角的决定性台词可以干净，有反差才有力量。

---

## 第三关：同场对照

1. 所有人的台词混在一起，遮名读一遍。认不出的，回档案。
2. 看关系：称呼从头到尾变了吗？变的时候是情节点吗？
3. 看弧光：结尾说话和开头有没有不一样？
4. 把这场戏拿给另一个模型或另一个人，只给档案和去名的台词（盲测）。

---

## 出关硬条件

**每一条都要过，过不了不算拷打完。** 有条件的写「不适用」并说明理由，不能默默跳过。

1. **设定不能丢**：设定里写了的地方出身、年龄、身份，改后的台词里要能听出来。怕方言写错，就用最稳的几个标记放在失控时（`ja/06` 第五节），不能整个删掉。
2. **有冲突的戏，至少一处下意识反应**：听到坏消息的那个人，第一个字是脱口的，出自他的档案（现代角色，`07a`）。
3. **至少一处 filler 或改口**，放在他在躲、在怕、在撒谎的地方；写实风格里每人的招牌 filler 不同。类型片和二次元按 `07a` 的密度。
4. **有一条语体线**：写出每个主要角色逐句的语体（如 敬语 → 敬体漏方言 → 常体）。有冲突的戏，至少一个人的语体要变，或者写明他为什么死守不变（守住本身就是戏）。
5. **不只是把错改对**：改完语法再问一遍「这句有没有变成他的」。只修了敬语、换谁说都行的，不算过。
6. **时长要真改**：超过镜头的台词，自己缩短或拆镜头给出定稿，不能只提醒。
7. **称呼和内外全对**（日语、古代逐句过）。
8. **跑脚本**：日语 `ja`，古代 `era`，英文 `variety`，把结果贴在产出里。跑不了就写明没跑，不算通过。
9. **不加戏**：拷打改的是怎么说，不是发生了什么。不新增情节、设定和信息；句数大变、补了新内容的，单独列出来标「建议，待确认」，定稿版不带。
10. **连起来读一遍**：改完从头读，查因果和信息：谁什么时候知道了什么？这句是在回应哪句？删掉的台词有没有别的句子依赖它？（例：删了「我父亲是知府」，下一句就不能接「知府千金？」）

**自评要诚实**：每条写依据（哪一句），别只写「通过」。

用户说「你定」或没有用户可问时，上面的条件**一条也不减**：自己定，标〔推测〕，最后列出最想问的问题。

## 产出

- 语言档案 v1（每个主要角色），**现代角色必含下意识反应表和招牌 filler**。
- 语体线（每人一行）。
- 出关条件逐条的结果。
- 改后的台词 + 修改表（原句 → 改后 → 哪项测试 → 为什么）。
- 没定的问题，等用户拍板。
- 进分镜前的提醒：外语、方言、读音、脏话和审核、长台词镜头（`ja/07`）。

交给 `cinematic-director` 时，把**定稿台词和拍数**一起交，分镜按它排时长。
