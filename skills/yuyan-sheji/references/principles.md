# 底层原则

整个 skill 只有两条原则，其余都是它们的展开。

---

## 一、用词有阶级性

一个人的用词水平体现他的身份和阶级；**用词的精准度（articulate 的程度）体现他的教育、知识量、阶级和身份**。英文词汇量大，同一个意思常有三四档说法，这种区分比中文更明显。

所以一个人怎么说话，要由下面这组**语言坐标**一起推出来，不能只挑一个口音标签：

| 坐标 | 要问的 | 为什么要问 |
|---|---|---|
| 国别、地区、城乡 | 在哪长大？现在住哪？ | 决定变体和词表（flat / apartment，brekkie，嘎哈） |
| 出身阶级 | 父母做什么？在什么样的家里长大？ | 决定「底层语码」：压力大、喝醉、对家人时会退回去的那一套 |
| 现在的阶级 | 现在做什么、挣多少、和谁来往？ | 决定「表层语码」：在外面、在工作里用的那一套。出身和现在不一样的人有两套，最有戏 |
| 教育 | 读到哪一级？在哪读？读什么科？ | 决定用词档位和精准度；读古典学的会带拉丁语，读法学的会带法律拉丁语，理工科的比喻来自工程 |
| 职业和资历 | 干了几年？在行业里什么位置？ | 决定行话和语域，资深的人行话反而少，新人爱用 |
| 年龄和代际 | 哪年出生？青春期在哪几年？ | 俚语、语气词、网络梗停在他十五到二十五岁那几年 |
| 社群和族裔 | 在哪个社群里说话最放松？ | 决定社会方言（AAVE、粤语夹英文）和什么时候切换 |
| 母语和第二语言 | 英语 / 普通话是不是母语？还会什么语言？ | 决定外语夹用、语法上的迁移、找不到词时退回哪种语言 |
| 性格 | 外放还是压着？爱表现还是怕出错？ | 决定同一套坐标下的个人差异 |

几个例子，说明坐标为什么要叠着用：

- **语言变体近乎不同的系统**：黑人英语（AAVE）和标准美式英语在构词、造句上各有规则，要当成一套有自己语法的语言来写，不是标准英语加俚语（`02-社会方言与职业语域.md`）。
- **同一样东西，变体叫法不同**：澳洲英语叫早饭 brekkie、下午 arvo；英式说 flat、lorry、queue，美式说 apartment、truck、line（`01-国别地域与口音.md`）。
- **同一个国家里，用词分阶级**：Alan Ross 1954 年的论文和 Nancy Mitford 1955 年的文章把英国的这种现象叫「U 和 non-U」：上层说 napkin、loo、sofa，中下层说 serviette、toilet、settee（`04-用词水平与精准度.md`）。
- **代际**：同一个阶层，二十岁和六十岁的人用的俚语、缩写、语气词也不一样。
- **教育决定会不会夹外语**：英美受过古典教育的人吃饭、举杯、下结论时会顺嘴带一句法语或拉丁语，装腔的人则用得太多、用错（`05-外语夹用.md`）。

可以参考的理论：

- Basil Bernstein 的**限制性语码 / 精致语码**（restricted / elaborated code）：工人阶级家庭的话更依赖在场的共同语境（代词多、省略多、理由不说出来），中产家庭的话更显式（把理由、条件、例外说出来）。
- William Labov 1966 年在纽约三家百货公司的调查：店员发 r 音的比例按商店档次分层；后来他又发现中下阶层在「小心说话」时会**矫枉过正**，比上层还用力（这正是「为了显得体面用大词用错」的来源）。
- **但要记住 Labov 1969 年对 Bernstein 的批评**（*The Logic of Nonstandard English*）：非标准变体的说话人推理一样严密，限制性语码不等于笨。档案里写「他不说理由」，不写「他说不清楚」。

## 二、自下而上：档案是提示和约束，不是定死的规则

角色是自下而上长出来的：先有几场戏、几句说对了的台词，人物才慢慢立住。语言档案也一样。

### 档案是活的

- 第一版只写有把握的几条，其余标「待定」。
- 台词越写越多，从「这句像他、那句不像」里反推规则，补进档案。
- 每次改都升版本号，写清**改了什么、来自哪句台词、为什么**。

### 每条写成「倾向 + 边界 + 例句」

| 部分 | 写什么 | 例 |
|---|---|---|
| 倾向 | 他通常怎么说 | 多用短句，主语常省；偶尔一句很长的抱怨，一口气说完 |
| 边界 | 他绝不会怎么说 | 不会说 furthermore、moreover；不会说「综上所述」 |
| 例句 | 1–3 句示范 | *Told him twice. Twice.* |
| 来源 | 这条从哪来 | 〔样本〕〔台词〕〔推测〕〔待定〕 |

- **给例句，不给配额。** 「三句里一句带脏字」可以当参考，不要写成指标去凑。
- **口头禅写频率上限**：上限是防漫画化的护栏，不是要达到的数。
- **不写形容词。** 「说话粗鲁」是请模型猜；「不用完整句，主语经常省，从不说 please，骂人只用 damn 和 hell」才是给模型下单。这条和 juese-sheji 的写法规则同源。

### 来源标记

| 标记 | 意思 | 什么时候升级 |
|---|---|---|
| 〔样本〕 | 从真人文字或转写里归纳出来，附原句 | 本身就是最高的 |
| 〔台词〕 | 从已写好、被认为「对了」的台词里归纳，附原句和场次 | 本身就是最高的 |
| 〔推测〕 | 只从身份标签推出来 | 写过几场戏、被台词证实后改成〔台词〕；被推翻就删 |
| 〔待定〕 | 还没想好，留空 | 有台词后补 |
| 〔待核〕 | 用到的语言学说法、方言词、外语短语没把握 | 查实后去掉；查不实就删 |

**从样本和台词里归纳，优先于从标签推演。** 有真实样本或已写好的台词时，先从它们里面归纳；只有一个身份标签时，推出来的东西全部标〔推测〕。

### 允许例外，并且记下来

人在特定处境下会说出不像自己的话：喝醉、求人、在法庭上、在孩子面前、被吓到。这正是戏。档案里有一栏「例外登记」：什么处境、破了哪条、怎么说。检查台词时，属于登记过的例外的，不算出戏。

## 三、反刻板的几条硬规矩

方言和社会方言写不好，就成了拿口音当笑料。下面几条不是风格建议，是底线：

1. **不靠拼错字模拟口音**（eye dialect：*dat*、*wuz*、*gonna* 满篇）。口音落到文字上靠**词表、语法和语用**；拼法最多保留一两个标志性的、该变体书面上也常见的写法（*y'all*、*gonna*、*innit*）。
2. **写语法规则，不堆俚语。** AAVE、澳洲英语、东北话都有规则；俚语是最容易过时、也最容易写成刻板的部分。
3. **方言角色要有和口音无关的目标、能力和幽默。** 他不是来负责好笑的。
4. **标准语也是一种口音。** 律师、英国上层、普通话播音腔都要写档案；只给少数族裔和方言角色写「特色」，等于把标准语当成没有口音。
5. **同一个社群内部有差异**：同样是 AAVE 说话人，在车间、在教会、在仲裁会上说法不同（会切换），年龄、地区、教育也会拉开。
6. **敏感词慎用**：族群蔑称、对残障的蔑称，剧情确实需要时，写进档案的「边界」或「例外」，说明谁、在什么情况下、对谁说，并在交付时提醒用户确认。
7. **借机制，不抄台词。** 拿真人或影视角色（Klaus、Lucifer）做参考，只借他们的语言机制（称呼、词表、语用习惯），不复制具体台词。
