# 8 修辞和用典

一个人的典故从哪来、比喻从哪个领域来，暴露的是他读过什么、干过什么、在哪长大。

---

## 典故的来源

| 来源 | 例 | 谁用 |
|---|---|---|
| 圣经（钦定本） | *the writing on the wall*、*salt of the earth*、*prodigal son*、*an eye for an eye*、*Good Samaritan* | 美国南方、黑人教会、老一辈英国人、牧师家庭长大的人 |
| 莎士比亚 | *to be or not to be*、*the lady doth protest too much*、*brave new world*、*method in the madness* | 受过英国式教育的人；美国人用多半是半句 |
| 古希腊罗马 | *Achilles' heel*、*Pyrrhic victory*、*crossing the Rubicon*、*Pandora's box*、*Sisyphean* | 古典学、律师、政客 |
| 体育（美） | *Hail Mary*、*out of left field*、*step up to the plate*、*a slam dunk*、*Monday morning quarterback* | 美国男性、销售、政客 |
| 体育（英） | *a sticky wicket*、*it's not cricket*（偏老派）、*an own goal*、*moving the goalposts* | 英国人；板球的偏上层和老派 |
| 军事 | *bite the bullet*、*in the trenches*、*collateral damage* | 军人、商人 |
| 流行文化 | 按年份：电影台词、广告语、梗 | 停在他十五到二十五岁那几年 |
| 中文：唐诗宋词、成语典故 | 「醉翁之意不在酒」「前度刘郎今又来」 | 读书人、老派 |
| 中文：毛选、语录、老电影台词 | 「同志们辛苦了」「为人民服务」「高，实在是高」 | 五六十年代生的人，常带调侃 |
| 中文：武侠小说 | 「江湖」「金盆洗手」「降龙十八掌」 | 七零八零后男性 |
| 中文：春晚小品、网络梗 | 按年份 | 停在他的年代；网络梗过时得最快 |

---

## 比喻从哪个领域来

**职业和经历决定比喻**：渔民用海和天气，程序员用代码和 bug，厨师用火候，修理工用机器，农民用庄稼，军人用战场，赌徒用牌局。这是最便宜、最有效的一招：观众听两句比喻就知道他干哪行。

档案里写：「比喻来自 ____；不会用 ____ 的比喻」。

---

## 修辞习惯

| 修辞 | 例 | 谁用 |
|---|---|---|
| 反讽 | *Oh, brilliant.*（指搞砸了） | 英国人、看透了的人 |
| 轻描淡写 / 反语曲言（litotes） | *not bad*、*not unlike*、*hardly ideal* | 英国人、律师 |
| 夸张 | *I've told you a million times* | 东北话、美国人、小孩 |
| 三连（tricolon） | *We will fight, we will win, we will remember.* | 政客、律师、布道的人 |
| 反问 | *You think I don't know that?* | 压人、委屈 |
| 先夸后贬（backhanded compliment） | *You're braver than I'd be, wearing that.* | 上层、刻薄的人 |
| 设问自答 | *Do I like it? No. Will I do it? Yes.* | 演讲的人、律师 |

---

## 写进档案的格式

```
修辞和用典：
- 典故来源：圣经（母亲是教会执事）、底特律活塞队
- 比喻来源：机器、变速箱、车库
- 修辞习惯：夸张少，反问多；从不三连
- 边界：不会引莎士比亚，不会用古典典故
- 例句：Man's running on bald tires and calling it faith. 〔推测〕
```
