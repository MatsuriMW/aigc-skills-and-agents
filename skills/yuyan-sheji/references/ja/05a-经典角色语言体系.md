# 经典角色的语言体系

黑帮、不良、热血少年、JK 这些角色，说话明显和普通人不一样，而且不是加一个语尾的事：它们有自己的秩序、称呼、词汇和说话规矩。写的时候要把**整套**写进档案。`05` 的配方表是速查，这一页是展开。

## 一个人设分三层

| 层 | 是什么 | 对应风格 | 例：黑帮说「别碰那件事」 |
|---|---|---|---|
| 真实 | 现实社会方言和行话，克制，很多词外人听不到 | 现实 | その件は、もう触らんほうがええと思いますよ。 |
| 影视化 | 电影、电视剧放大过的版本，观众已经默认 | 二次元·轻；也用于类型片式的现实剧 | 兄ちゃん、その話には首突っ込まんほうが身のためやで。 |
| 漫画化 | 夸张、招牌化 | 二次元·重 | テメェ、その件に手ェ出してみろ。東京湾に沈めてやらぁ！ |

**先选层，再写台词**。现实短剧要写第一层或轻一点的第二层；真人演员说第三层是搞笑。

每一节都按这个顺序写：**秩序 → 人称和称呼 → 句末 → 词 → 规矩 → 切换 → 三层对照 → 穿帮**。例句都是示意，不是语料。

## 一、黑帮（ヤクザ、極道）

**秩序**：拟亲属。盃（さかずき）结成亲子、兄弟，组长是「父亲」，所有称呼都从这里来。大组织一层套一层。

| 称呼 | 指谁 | 怎么用 |
|---|---|---|
| 親分、組長、会長 | 老大 | 当面叫 **オヤジ**，对外说「うちの親分」 |
| 若頭 | 第二号人物 | 当面叫 **カシラ** |
| 兄貴 | 比自己早入门的 | 当面最常用 |
| 叔父貴（オジキ） | 组长的兄弟 | 表示辈分 |
| 姐さん（あねさん） | 组长或大哥的妻子 | 下面的人说敬语 |
| 舎弟 | 老大或大哥的「弟」 | 分寸比「若い衆」高 |
| 若い衆、若いの | 年轻手下 | 老大说：おい、若いの呼べ |
| カタギ | 圈外的普通人 | 「カタギには手を出すな」是常见的自我标榜 |

**人称**：自称 俺、ワシ（関西、広島、年长者）、私（对上、对外）。叫手下 お前、名字。叫外人 兄ちゃん、あんた、お宅、社長（奉承）。敌对 てめえ、貴様；関西ワレ、おんどれ。

**句末**

| 地区 | 句末 | 例 |
|---|---|---|
| 关东 | 〜じゃねえか、〜だろうが、〜んだよ、〜だぞ、ナメてんのか | 話が違うじゃねえか。 |
| 关西 | 〜やろが、〜やないか、〜たろか、〜んかい、なめとんのか、いてまうぞ、しばくぞ | 話がちゃうやないか。 |
| 広島（仁侠电影味） | 〜じゃけえ、〜んじゃ、おどれ、〜のう | 話が違うじゃろうが。 |

方言照 `06` 的规矩：断定、否定、理由三处一致。

**词**

| 词 | 意思 | 备注 |
|---|---|---|
| シノギ | 赚钱的活 | |
| シマ、縄張り | 地盘 | 博徒系说縄張り，テキ屋系说庭場 |
| みかじめ（料）、ショバ代 | 保护费、摊位费 | 前者偏赌徒系，后者偏テキ屋系 |
| ケジメ、落とし前 | 交代、负责 | 「どう落とし前つけるんや」 |
| 破門、絶縁 | 逐出 | 绝缘比破门重 |
| 盃 | 结拜、认父子 | |
| カチコミ | 打上门 | 影视味 |
| 鉄砲玉 | 被派去送死的小弟 | 影视味 |
| チャカ、ハジキ | 手枪 | 影视味，现实较少听到 |
| サツ、マッポ | 警察 | |
| ムショ | 监狱 | |

**规矩**

- **越高位，话越少、越客气**。喊的是小弟。真正吓人的老大用敬体慢慢说。
- **不明说**：威胁靠暗示（「兄ちゃん、体は大事にせなあかんで」「ご家族、お元気ですか」）。
- **对上绝对服从**：下对上只有 はい、失礼します、ご苦労様です、お疲れ様です！ 声音大，九十度鞠躬。
- 很讲究客套和礼数：见面、谢恩、问候。出狱时「お勤めご苦労様でした」。

**切换**：对老大满格敬体 → 对小弟短常体 → 对外人表面客气 → 翻脸时瞬间变。

**三层对照**（同一句：钱呢）

- 真实：あの件、まだお返事いただいてませんよね。
- 影视：金、いつになったら返してくれるんや、社長。
- 漫画：金はどうしたァ！ コラァ！

**穿帮**：所有黑帮都大喊；小弟对老大常体；东京组织全说関西腔；现实短剧里满口チャカ、カチコミ；同时用関西和広島方言。

## 二、不良（ヤンキー）

**秩序**：学校和地盘内的强弱，加上严格的前后辈。

**分年代**，这是最容易错的地方：

| 年代 | 叫法 | 词和说法 |
|---|---|---|
| 70–80 年代 | ツッパリ、番長、スケバン、暴走族 | タイマン、上等だ、ガン飛ばす、シメる、夜露死苦（「よろしく」的当て字，主要写在特攻服和涂鸦上，读音还是 よろしく）、総長、特攻服 |
| 90–2000 年代 | ヤンキー、チーマー | パシリ、チクる、カツアゲ、ダチ、マブダチ |
| 现在 | 少了很多，地方上的 ヤンキー、半グレ | は？、あ？、うっせえ、だるい、キモ、死ね、なめてんの |

**人称**：自称 俺、オレ；女生 あたし、うち。叫对方 てめえ、お前、テメー；叫朋友 名字、あだ名。

**句末和语法**

- ai → ee：うるせえ、知らねえ、ふざけんじゃねえ。
- 〜っつってんだろ、〜じゃねーよ、〜だコラ、〜オラ。
- 动词前缀：ぶっ殺す、ぶっ飛ばす、ぶん殴る、ど突く、ふざけんな。
- 省略多：何見てんだよ。

**规矩**

- 对前辈突然守规矩：ちわっす、うっす、〜っす。**这个切换是这个体系的灵魂**。
- 重义气：「ダチ」「筋を通す」。女生（スケバン）也是这套，句末 〜だよ、〜じゃねえよ，自称 あたし。
- 漫画和电影里打架前要有一轮互相喊话，现实不这样。

**三层对照**（同一句：你看什么）

- 真实：……なに。
- 影视：何見てんだよ。
- 漫画：あァん？ テメェ、どこ中だコラァ！

**穿帮**：2026 年的高中生说「夜露死苦」（要有时代或恶搞理由）；不良对前辈也骂；只有粗话没有规矩；女不良用「わよ」。

## 三、热血少年（少年漫画主角）

**秩序**：师傅、伙伴、对手。不看地位，只认实力和决心。对谁都一样直接。

**人称**：自称 **俺**（常写オレ，显得年轻）。1960 年代后期起，少年漫画的主角从优等生转向顽童，「俺」就成了主流。叫对方 お前；敌人 てめえ；叫师傅 師匠、じいちゃん；伙伴直接叫名。**少数主角用「僕」**，深夜动画和内向型更多，那是另一种人，不要混。

**句末**：〜ぜ、〜だぜ、〜ぞ、〜んだ！、〜ねえ！、〜だろ！、〜だ！

**词和句式**

| 类 | 例 |
|---|---|
| 决心 | 絶対に、必ず、諦めねえ、負けねえ、強くなる、守る |
| 约定 | 約束だ、〜してやる、〜してみせる |
| 伙伴 | 仲間、一緒に、お前らがいたから |
| 不解 | なんでだよ！、ふざけんな！、どういうことだよ！ |
| 喊 | うおおお！、行くぞ！、まだだ！ |
| 日常 | 腹減った、飯、うめえ！ |
| 招式 | 喊招式名，全名，慢慢喊 |

**规矩**

- **词简单，句子短，主张直白**。不用敬语（对长辈也一样，别人会骂他），不说缓冲语，不说暗示的话。
- 同一个决心反复说，但每次要有新的具体的事。
- 反应快：先吼，再想。
- 对敌人也说心里话，甚至问对方为什么。
- 成长弧：结尾开始会说「ありがとうな」，或者第一次用敬语，那一句就是高潮。

**子类型**

| 子类 | 差别 |
|---|---|
| 笨蛋元气型 | 不懂难词、读错字；饿 |
| 努力型 | 更安静：まだ、やれる。もう一本。 |
| 运动番 | 对前辈 〜っす，对同级常体 |
| 冷酷对手（クール系） | 〜だ。、〜か。 短句；台词少，「〜だ。」说死在这里才是对的 |
| 僕主角 | 〜だよ，内心独白多，关键时刻才喊 |

**三层对照**（同一句：我不会放弃）

- 真实（运动部少年）：まだ、やれます。もう一本お願いします。
- 影视：俺、絶対諦めないっす。
- 漫画：諦めるもんか！ 俺は絶対に、お前に勝つ！

**穿帮**：说话复杂、有缓冲；每句都〜だぜ；对敌人说敬语（除非是人设）。**不要用一听就知道是哪部作品的招牌**（固有语尾、倒装的梦想宣言、名台词），只用这个类型公共的部分。

## 四、JK（女子高中生）

**先记两条**：

1. **这是未成年角色**，只写日常、友情、学校、喜欢的东西，不写性暗示。女仆、妹系等涉及未成年时同样。
2. **现实 JK 和动画 JK 是两种说话**。动画女主常说「〜だよ」「もう！」；现实的更快、更短、更多网络词。

**秩序**：同学关系、小团体、前后辈（部活）。对老师半敬语。

**人称**：自称 **うち**、あたし、私、名字；ギャル あーし。叫对方 名字、あだ名、〜ちゃん；男生 名字くん、呼び捨て；老师 先生、あだ名。

**句末**：〜じゃん、〜なんだけど、〜だし、〜だよね、〜じゃない？、〜かも、〜って、〜みたいな、〜すぎ、〜くない？（不用わ、かしら）

**词的分层**（重要）

| 层 | 例 | 怎么用 |
|---|---|---|
| 稳定的口语，放心用 | やばい、まじ、えぐい、それな、わかる、てか、ガチ、うける、むり、しんどい、かわいい、〜すぎ、ちょっと待って、え、待って | 主要靠这层 |
| 新词，有保质期 | メロい、〜でしぬう、自認〇〇、〇〇で今これ、スピ活（AMF「JC・JK 流行語大賞 2025」コトバ部門） | 一场戏最多一个。**定好片子的年份**，过一两年就老了 |
| 过时的词 | チョベリバ（90 年代）、ぴえん（2020 年前后） | 只用于年代或自嘲 |
| 写的，不是说的 | 上面榜单里不少词主要用在 Instagram、TikTok 的文字上（如「〇〇で今これ」）；りょ、おつ、草 | 写屏幕文字时用；用嘴说要有理由 |

**语法特征**

- 形容词词干结束：やば。えぐ。うま。さむ。
- 句子说一半，语尾拖长（现实有，别写成ですぅ）：まじでー、それなー。
- 附和极多：え、わかる、それな、まじ？ 对话往往是两人重叠的短句。
- 〜すぎ：かわいすぎ、ねむすぎ。

**子类型**

| 子类 | 差别 |
|---|---|
| 普通 | 上表 |
| ギャル | あーし、うち；〜じゃね、〜だし、ガチで、〜しか勝たん、声大 |
| 优等生、班长 | 私；〜だよ、〜でしょ；老师面前规矩；用词准 |
| 名门女校 | 敬语好、缓冲多；`05` 的お嬢様语是漫画版，现实是 `examples/09` 年轻时的样子 |
| 宅女 | 早口；推し、尊い、無理、しんどい；对同好话多，对外人话少 |
| 动画女主 | 私；〜だよ、〜だね、〜なの；もう！、えへへ；比现实慢、完整 |
| 体育系 | 前辈 〜っす、はい！；同学常体 |

**切换**：朋友（常体、快、词多）→ 老师（半敬语：先生、それ、やばくないですか）→ 打工（バイト敬語）→ 父母（不耐烦的短句：は？、べつに、わかってるって）。

**三层对照**（同一句：这家店很好吃）

- 真实：え、ここうま。やば。
- 影视：ここ、めっちゃおいしくない？
- 动画：わぁ、おいしい！ ここ、すっごく気に入っちゃった！

**穿帮**：満口「〜だわ」「〜かしら」；一句塞三个新词；中年人写的 JK 词（用力过猛，日本观众一听就知道）；现实短剧里说动画腔；把屏幕文字念出来。

## 五、其他常见体系（速查）

| 体系 | 人称和称呼 | 句末 | 词和规矩 | 真实 vs 夸张 |
|---|---|---|---|---|
| **刑事** | 俺、私；嫌疑人 お前、あんた；同僚 名字 | 〜だな、〜だろ、〜か；问话时敬体 | 真实现场用マルヒ（嫌疑人）、マルガイ（被害人）、現着（到场）；ホシ、デカ 是影视味；ホトケ、ハジキ 现在不太听到 | 真实：話を聞かせてもらえますか。夸张：吐けよ、お前がやったんだろ！ |
| **姉御** | あたし；あんた、お前、坊や | 〜だよ、〜だね、〜かい、〜しな | 干脆、照顾人、抽烟喝酒的前辈感 | 〜しな 是影视味；现实：〜だよ、〜しなよ |

| **昭和父亲、老上司** | 俺、わし（西）、私；お前、おい、〜くん | 〜だ、〜か、〜しろ、〜たまえ（极少） | 「おい」「飯」；不解释；说教 | 现代已少，要有年代理由 |
| **大阪大婶** | うち、あたし；あんた、兄ちゃん | 〜やで、〜やん、〜やろ、〜してんの | 自来熟、飴ちゃん；要有真人的目的，不只是搞笑 | 飴ちゃん 是刻板印象，少用 |

| **医生** | 私、僕；患者さん、〜さん | 〜ですね、〜しましょう | 对患者通俗，同事面前术语 | 无 |
| **老师** | 先生、私、俺；〜さん、〜くん、お前 | 常体 + 〜なさい、はい | はい、静かに；熱血教師是影视味 | 无 |

## 六、写进档案

经典角色的档案在普通字段外，多写这几项：

- **层**：真实、影视、漫画中的哪一层。
- **体系内位置**：在这个秩序里他是上还是下（若头 vs 小弟；总长 vs 新来的）。**体系内的上下切换，是这类角色的灵魂**。
- **词的年份**：片子的时代，俚语定在哪一年。
- **体系外的他**：他和这个类型不一样的地方。黑帮喜欢插花，不良照顾弟弟；只靠类型撑起来的就是贴纸（`../principles.md` 第三节）。
- **在什么时候破功**。

**组合时**：黑帮老大对女儿、不良在打工、JK 在面试，类型和场面叠加时，**场面的规矩优先**，类型从缝里露出来。这里最出彩。

**固有作品**：只用类型的公共特征，不用特定作品的招牌词、名台词。

**敏感边界**：不把真实组织的名字、真实的犯罪方法写进台词；黑帮和不良不美化到像广告；地区不等于黑帮（関西腔不是坏人专用）；未成年角色不写性暗示。
