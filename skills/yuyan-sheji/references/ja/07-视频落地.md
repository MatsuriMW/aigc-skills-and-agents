# 做视频：读音、时长、交付

台词写对了，读错了照样穿帮。这一页管日语台词从文字到视频的最后一步。音色、语速参数归 `peiyin`，这里管**写在台词里的**东西。

---

## 一、读音：汉字要消歧

日语汉字有多种读法，TTS 和视频模型靠猜。「わたくし」的角色读成「わたし」，人设就没了；「わらわ」写成「妾」可能读成「めかけ」。**一定要在目标引擎上试听一次**，不同引擎的默认读法不同。

**规则**：

1. **交付两版**：显示版（汉字假名混写，给字幕）和念白版（送 TTS 或视频模型，容易错的词改成假名）。
2. **人称词、役割语一律写假名**：わたくし、わらわ、おぬし、それがし、なんじ、まろ。念白版里，不写汉字。
3. **片假名外来语照写**；不写罗马字（Wi-Fi 写ワイファイ，AI 写エーアイ）。
4. **数字、日期、单位写假名或汉字念法**。
5. 助词「は」「へ」：个别 TTS 会读错成 ha、he（语言学习平台的用户常抱怨），用引擎试听；出错时念白版可以写「わ」「え」，只在念白版这么写。
6. 引擎支持 SSML 的，可以用 alias 或 ruby；不支持时，用假名。

## 二、时长：拍数（モーラ）

日语按拍（mora）算长度：か＝1、きょう＝2、かん＝2、がっこう＝4。

- 语料参考：朗读约 7.1 拍/秒，模拟讲演约 8.0 拍/秒（CSJ）；NHK 这样的广播节目大约 7.5–9.5。
- **做视频建议先按 6 拍/秒算**（台词要留气口和表演），上限 8。这是按语料放宽后的估算，到目标引擎上实测再调。
- **角色的速度不同**：老人、大小姐、执事慢；不良、推销员、吐槽役快。

| 镜头时长 | 大约能放（按 6–8 拍/秒） | 例 |
|---|---|---|
| 3 秒 | 18–24 拍 | ちょっと待ってください。（12 拍） |
| 5 秒 | 30–40 拍 | |
| 10 秒 | 60–80 拍 | |

**敬语很占时长**：行きます（4 拍）→ 伺わせていただきます（12 拍）。给客户的长敬语放在 5 秒镜头里就会抢拍。三种办法：换短的敬语（参ります）；拆成两个镜头；说一半（言いさし）。

**中文转日语时**：中文剧本的一句话翻成日语经常变长，分镜时间要重排，不要假定一样长。

## 三、给视频模型和配音

| 项目 | 做法 |
|---|---|
| 台词 | 念白版，引号写清，例如 `「少々お待ちくださいませ」` |
| 语种 | 明确写「日语台词，标准东京腔」或「関西腔」，否则模型可能跑调。需要方言时，一次只能写清一种 |
| 语气 | 写情绪和说话方式（低声、不耐烦），不写 NHK 口吻以外的抽象词 |
| 语调 | 句末上扬表示问句，用「？」写明；女性语的「わ」要上扬，関西的「わ」下降，这在 prompt 里要提醒 |
| 配音 | 把读音表和角色语速交给 `peiyin`；日语外来语和人名也要给 |
| 口型 | 长敬语放在特写上容易对不上口型，优先放在中远景或背影 |

## 四、文字和字幕

- **简体字混入**：说、这、对、门、时 这些字在日语字幕和念白里不能出现。脚本 `ja` 会扫。
- **同形不同义的汉字**：手紙（信）、丈夫（结实）、大丈夫（没事）、娘（女儿）、勉強（学习）、人参（胡萝卜）。直接从中文挪过来可能写错意思。
- **日语标点**：。、「」，问号感叹号全角；句号在台词气泡里常省。
- **中文字幕对应**：日语的人称和句末在中文里很难留下来。字幕翻译的意图放在「称呼」和语气词上，不要因为字幕翻不出来，就把日语改得简单。
- **档案是日语台词的正本**，中文字幕由它派生。

## 五、机器检查（脚本 `ja`）

```bash
python3 scripts/yuyan_tool.py ja 台词.md --speaker 名字 --style real --self 俺,僕 --sec 6
```

能查：简体字混入、人称使用（`--self` 外的自称都报）、现实风格里的役割语（`--style real`）、已知的敬语错误、句末分布（「〜だ。」说死的比例）、易错读音、估算拍数（`--sec` 给镜头秒数）。

查不了：敬语方向是否对（要看谁做的）、内外、人物像不像。这些必须按 `00` 的七步人工过一遍。
