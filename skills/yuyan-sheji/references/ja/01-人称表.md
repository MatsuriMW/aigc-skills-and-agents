# 日语人称表：自称、对称、他称、谦称

先记三条：

1. **能省就省**。日语靠动词、敬语和场面判断是谁，人称词一多就是翻译腔。档案里的人称表，只有该说的时候才用。
2. **同一个人有好几个自称**。NINJAL 日常会话语料里一个 30 多岁的男性：对妻子和后辈说「俺」，对岳母和妻子的朋友说「僕」，对职场前辈和年长的熟人说「私」；岳母在场时对妻子也改说「僕」。一个 60 多岁的男性讲到让他生气的事，自称会临时跳回「俺」。**所以档案写「对谁用哪个」，不写「他的自称是 X」。**
3. **对长辈和上级，不用人称代词称呼对方**（鈴木孝夫的规律）。用职务、「先生」「先輩」、亲属称谓或「名字 + さん」。

「现实」列：◎ 日常用 ／ ○ 特定人群用 ／ △ 现实少见，用了就有色彩 ／ ✕ 现实基本不用（只在二次元、玩笑或年代戏里）。

## 他称（说到第三人）

| 词 | 用法 | 注意 |
|---|---|---|
| 名字 + さん／职务 | **默认** | 说到人，最自然的是直接说名字，不是说「彼」 |
| 彼、彼女 | 同辈或下级；「彼女」「彼氏」也指恋人 | 说上级不用；翻译腔的高发区；「彼女」常被理解成女朋友 |
| あの人、あの方 | 「あの方」敬称；「あの人」不算尊敬，夫妻间也用 | |
| こちらの方、あちらの方 | 当面介绍 | |
| この人、その人 | 中性，当面说略失礼 | |

## 谦称和敬称（说自家人和别人家的）

对外说自家，用左列；说对方家，用右列。这是内外（`02`）在名词上的表现。

| 东西 | 说自家（对外） | 说对方的 |
|---|---|---|
| 父亲、母亲 | 父、母（成年人）；家里叫お父さん | お父さん、お父様、お母様 |
| 丈夫 | 夫、主人（后者现在有人不喜欢） | ご主人、旦那さん |
| 妻子 | 妻、家内、嫁（関西来的说法，年轻人多用，有人反感）、かみさん（老派、随便） | 奥さん、奥様 |
| 儿子、女儿 | 息子、娘、うちの子 | 息子さん、娘さん、お子さん、ご子息、お嬢さん、ご令嬢 |
| 兄弟姐妹 | 兄、姉、弟、妹 | お兄さん、お姉さん、弟さん、妹さん |
| 公司 | 弊社、小社；对内说「当社」「うち」 | 御社、貴社、そちら |
| 家 | 拙宅、うち | お宅、ご自宅 |
| 东西 | 粗品、つまらないものですが、ほんの気持ちです | 結構なもの |
| 作品 | 拙著、拙作 | ご著書、ご高著 |
| 意见 | 私見、愚見 | ご意見、ご高見 |

- 「愚妻」「愚息」「豚児」现实基本已经不说，年代戏或老人才用，用了要当作性格。
- 成年人**对外**说「うちのお父さんが」会显得幼稚，这是日语老师常抓的一个点；学生和年轻人也有这么说的，看人设。
- 男性随便的场合说自家父母：親父（おやじ）、お袋（おふくろ）。

## 叫法随关系变

称呼的变化就是关系的变化，写进档案的版本记录和分镜：姓 + さん → 名 + さん → 名 + ちゃん／くん → 只叫名。**一场戏里第一次改口，要当作情节点来写**，不要无意间换。
