# 对象矩阵：谁对谁、怎么说

这一页回答：男性对同辈、上级、下级怎么说；女性对同辈、上级、下级怎么说；男女之间怎么说。

先记结论：

1. **关系比性别重要**。越正式，男女差别越小：职场对上级，男女的敬语几乎一样，只有自称和语气略有差别（男性「私」、女性「私」，都一样）。性别差别主要出现在**常体**和**亲近的关系**里。
2. **上下由所属秩序定**，不只看年龄。比自己大一届的「先輩」要敬；比自己小的上司也要敬；年长的下属，上司也常常用敬体（反过来的切换最有戏）。
3. **亲疏和上下分开算**：上司也可以很熟（敬体但放松），同学也可以不熟（同辈但敬体）。
4. **同样的命题放在表里比较**，才知道拉开了没有。

下面用两个命题：「明天的会你能来吗」（请求）和「那不对」（反对）。现实风格，现代东京，职场；学校替换见后。

## 男性说话

| 对象 | 自称 | 叫对方 | 语体 | 请求 | 反对 |
|---|---|---|---|---|---|
| 同辈，很熟 | 俺 | お前、名字、あだ名 | 常体 | 明日の会議、来れる？ | それ違くね？／いや、違うだろ。 |
| 同辈，不熟 | 僕、俺 | 名字さん | 敬体（〜ます），句末轻 | 明日の会議、来られます？ | それ、ちょっと違う気がしますけど。 |
| 上级，常态 | 私、僕 | 部長、課長、名字さん | 敬语 | 部長、明日の会議ですが、ご出席いただけますか。 | 恐れ入ります、その点は少し認識が違っておりまして……。 |
| 上级，很熟（酒局、前辈） | 僕、俺（前辈允许时） | 先輩、名字さん | 敬体，放松 | 先輩、明日の会議って来れます？ | いや、それは違いますって。 |
| 下级，很熟 | 俺 | 名字、名字くん、お前（老派） | 常体 | 明日の会議、来れるか？ | それは違うな。 |
| 下级，保持距离（现代的上司） | 私、僕 | 名字さん | 敬体或常体 | 明日の会議、来られますか？／来れる？ | そこはちょっと違うかな。 |
| 年长的下级 | 私、僕 | 名字さん | 敬体 | 明日の会議、お願いできますか。 | そこは少し違うと思うんですが。 |
| 客户 | 私（わたくし） | 様、御社 | 满格 | 明日の会議にご足労いただくことは可能でしょうか。 | 恐れ入りますが、弊社の認識とは少々異なるようでございます。 |

## 女性说话

| 对象 | 自称 | 叫对方 | 语体 | 请求 | 反对 |
|---|---|---|---|---|---|
| 同辈，很熟 | 私、あたし、うち（年轻） | 名字、あだ名、ちゃん | 常体 | 明日の会議、来れる？ | それ違くない？／いや、違うでしょ。 |
| 同辈，不熟 | 私 | 名字さん | 敬体 | 明日の会議、来られますか？ | それ、ちょっと違うかなって思うんですけど……。 |
| 上级，常态 | 私 | 部長、名字さん | 敬语 | 部長、明日の会議ですが、ご出席いただけますか。 | 恐れ入ります、その点は少し認識が違っておりまして……。 |
| 上级，很熟 | 私 | 先輩、名字さん | 敬体，放松 | 先輩、明日の会議って来れます？ | えー、それは違いますよ。 |
| 下级，很熟 | 私 | 名字さん、名字ちゃん | 常体 | 明日の会議、来れる？ | それはちょっと違うかな。 |
| 下级，要压住（40 岁以上更常见） | 私 | 名字さん | 常体，句末硬 | 明日の会議、出てね。 | それは違うわよ。／ 違うでしょ。 |
| 年长的下级 | 私 | 名字さん | 敬体 | 明日の会議、お願いできますか。 | そこは少し違うと思うんですが。 |
| 客户 | 私（わたくし） | 様、御社 | 满格 | 同上（与男性相同） | 同上 |

**看表就知道**：对上级和客户，男女两列几乎一样。不要因为说话人是女性，就在敬语后面硬加「〜わ」。

## 男女之间

| 关系 | 男 → 女 | 女 → 男 | 要点 |
|---|---|---|---|
| 同班同学、不熟 | 名字さん；僕、俺；常体 | 名字くん；私；常体 | 男生对女生叫「お前」会被反感 |
| 同事、不熟 | 名字さん；敬体 | 名字さん；敬体 | 职场一律「さん」最安全 |
| 同事、很熟 | 名字さん；常体 | 名字さん、名字くん（年长女性对年轻男性）；常体 | 男上司对女下属叫「ちゃん」就是职场问题，可以用来写人物 |
| 刚开始约会 | 名字さん；僕或私；敬体和常体混合 | 名字さん、名字くん；敬体和常体混合 | **敬语掉下来的那一刻就是关系变化** |
| 恋人 | 名、あだ名；俺；常体 | 名、名くん、あだ名；私、あたし；常体 | 「君」现实里少，「お前」看人，有人讨厌 |
| 夫妻 | 名、お前（老派）、ママ（有孩子后） | 名、あなた（老派）、パパ | 有孩子之后互叫爸爸妈妈很常见；中老年「おい」「ねえ」 |
| 夫妻吵架 | 常体加硬：何だよ、もういいよ。 | 敬体降温：はい、分かりました。 | 对方突然用敬体说明很生气 |
| 女上司 → 男下属 | | 名字さん、名字くん；常体或敬体 | 男下属用标准敬语，不因为性别不同 |
| 姐弟恋、年长的女性 | 敬体到常体慢慢变 | 名字くん、常体 | 称呼是看点 |

**混合场面会改变说法**：男性对妻子本来说「俺」，岳母在场时可以说「僕」（NINJAL 的实例）。其他人在场时，「内部用语」也要收。

## 学校和部活

| 关系 | 说法 |
|---|---|
| 后辈 → 先辈 | 先輩＋敬体：先輩、明日の練習、来ますか？运动部男生：来るっすか？／うっす。 |
| 先辈 → 后辈 | 名字（呼び捨て）＋常体：明日、来いよ。／来れる？ |
| 同级 | 常体，名字＋くん／さん／呼び捨て／あだ名 |
| 学生 → 老师 | 先生＋敬体；关系好时混一点常体（「先生、それマジ？」） |
| 老师 → 学生 | 名字＋さん／くん／呼び捨て，常体：明日、来なさい。／来られるか？ |
| 中小学 | 高年级才开始有前后辈敬语 |

**一年之差就要用敬语**，这是中文观众不熟、却是日本校园剧的基础。

## 家庭

| 关系 | 说法 |
|---|---|
| 孩子 → 父母 | 常体。お父さん、お母さん、パパ、ママ。男生长大后：親父、おふくろ（当面叫少）；家境好的有「お父様」，现实少见 |
| 父母 → 孩子 | 名字、ちゃん、くん，常体。自称お父さん、お母さん |
| 弟妹 → 兄姐 | お兄ちゃん、お姉ちゃん、兄貴（男）、ねえちゃん；常体 |
| 兄姐 → 弟妹 | 只叫名字，常体 |
| 对祖辈 | おじいちゃん、おばあちゃん；常体 |
| 对公婆、岳父母 | お義母さん；敬体（お義母さんの方が……） |

上位的亲属不能被直接叫名字，这是鈴木孝夫说的规律，也是中文剧本翻过来时最常犯的错：妹妹直接叫哥哥的名字，要有戏剧理由。

## 一句话里的切换信号（情绪，第 10 维）

| 从 → 到 | 意思 |
|---|---|
| 敬体 → 常体 | 变亲近（第一次说「タメ口でいいよ」）；或者发怒、失控、瞧不起 |
| 常体 → 敬体 | 突然生气、拉开距离、讽刺、郑重（告白、求婚、道歉） |
| 俺 → 僕／私 | 有外人、想装礼貌、心虚 |
| 僕／私 → 俺 | 露出真面目、暴怒、私下 |
| 姓 → 名 | 关系推进 |
| 名 → 姓 | 分手、冷战 |
| 東京话 → 方言 | 放松、回老家、发火（`06`） |
| 现实 → 过度敬语 | 慇懃無礼的攻击（`02`） |

这张表是**写戏的工具**：场景里有冲突时，让台词在这里切一次，比加一句台词更有效。写进档案的「例外登记」。

## 二次元的切换

二次元·重的角色也要有切换，否则就是贴纸：

- 大小姐：对长辈、外人敬语满格；对女仆常体（お茶をちょうだい）；只对青梅竹马漏出普通的说法，这是最大的萌点。
- 魔王：对所有人都是「我／汝」，只在女儿面前说「パパ」，就是喜剧。
- 老武士：对主君「拙者」「〜にございます」，对后辈「わし」「おぬし」。

具体见 `05`。
