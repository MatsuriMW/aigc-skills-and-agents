# 性别表现和句末

**日语的句末是最容易把人写假的地方。** 教科书和影视剧里的「女性语」「男性语」，比现实夸张得多。

---

## 一、现实：年轻人已经很中性

水本光美等人的研究反复发现：大约 80 年代末起，年轻女性（标准语）说话已经不用传统的女性句末（〜わ、〜かしら、名词 +よ、〜のよ），而是和男性用一样的「〜だね」「〜かな」「〜だよ」。但电视剧里同年龄的女性角色仍然大量使用，日语教材里的出现比例是实际会话的十倍以上。

所以：

- **现实风格写 40 岁以下的女性，默认不用「〜わ」「〜かしら」「〜のよ」**。
- 模型受教材和小说影响，会默认写「素敵だわ」，这是最常见的穿帮之一。
- 上了年纪的女性、上层家庭出身的女性、播音腔，保留得多一些。
- 现实里「〜わ」偶尔还在：感叹（「これは無理だわ」，下降语调，男女都用）。**関西的「行くわ」「知らんわ」是男女通用的下降语调**。女性语的「わ」是上升语调。TTS 读不出差别时，这个差别在台词里就要避开。

## 二、句末对照

「现实」列是今天 40 岁以下的东京话大致情况。

| 意思 | 偏男性（现实） | 偏女性（现实） | 中性（最常见） | 传统女性语（现实已少） | 传统男性语（现实已少） |
|---|---|---|---|---|---|
| 判断 | 〜だ、〜だよ | 〜だよ、〜なの | 〜だよ、名词结束 | 〜だわ、〜よ、〜のよ | 〜だぜ、〜だぞ |
| 确认 | 〜だろ | 〜でしょ | 〜だよね、〜じゃん | 〜でしょう？ | 〜だろう |
| 感叹 | すげえ、やべえ | すごい、やばい | すごい、やば | すてきだわ、まあ | 〜だなあ |
| 疑问 | 〜か？、〜のか | 〜の？ | 〜？（上扬）、〜の？ | 〜かしら、〜の？ | 〜かね |
| 邀约 | 行こうぜ、行かね？ | 行こうよ | 行こう、行かない？ | 行きましょうよ | |
| 命令、请求 | 行け、行ってくれ | 行って、行ってよ | 行って | 行ってちょうだい | 行きたまえ |
| 否定 | 違え、違うだろ | 違うよ、違うって | 違う、違くない？ | 違うわ | |
| 主张 | 〜んだ、〜んだよ | 〜の、〜んだよ | 〜んだ | 〜のよ | 〜のだ |

- **ai → ee 音变**（うるさい → うるせえ、すごい → すげえ、ない → ねえ、知らない → 知らねえ）：男性、粗；女性用了显得不良或很放松。
- **〜っす**：运动部的男后辈（マジっす、了解っす），现在年轻女性也有用；对上级是「半敬语」，正式场合不行。
- **じゃん**：出自关东，现在几乎全国的年轻人用。**〜じゃね？、〜くね？**：男性为主，年轻女性也有。
- **〜たまえ、〜かね、〜だね（训话）**：老派上司、教授。**〜なさい**：母亲、老师对孩子。**〜な（命令：行きな）**：下町大姐、老人。

## 三、口语缩约（现实必备）

模型默认写全形，实际说话几乎都缩。

| 全形 | 缩约 | 敬体里能用吗（○ 常见 / △ 放松的敬体可以，正式不用） |
|---|---|---|
| 〜ている | 〜てる | ○（してます） |
| 〜ておく | 〜とく | △ |
| 〜てしまう | 〜ちゃう、じゃう | △（随便的敬体可以） |
| 〜のだ | 〜んだ | ○（〜んです） |
| 〜では | 〜じゃ | ○ |
| それは | そりゃ | △（そりゃそうですよ） |
| 〜ければ | 〜きゃ（なければ以外は少） | △ |
| 〜なければ | 〜なきゃ | △（行かなきゃいけないんです） |
| 〜という | 〜って、〜っていう | △ |
| 何を | 何 | △ |
| 来られる | 来れる（ら抜き） | △ 年轻人和日常都这么说；正式不说；老派的人看不惯 |
| もの | もん | △（だって寒いんですもん） |
| 〜らない、〜るの | 〜んない、〜んの | △（わかんないです） |
| 本当 | ほんと | △ |
| すみません | すいません | ○ |

**老人、正式场合、播音、有洁癖的人**缩得少。这个差别可以当作人物特征。

## 四、句末留白（言いさし）

现实日语很多话不说完：

- 〜けど……、〜から……、〜し……、〜って感じ……
- 今日はちょっと……（拒绝）
- もう、いいです……

翻译腔的台词句句有完整谓语。**让一半的句子停在「けど」「から」上，立刻就活了。** 但是拍数里要留气口。

---

## 五、填充和附和

- 附和（あいづち）：うん、はい、ええ、そうそう、へえ、なるほど、まじで、ほんとに。对话里听的人几乎每句都有。写台词要留位置。
- 开口填充：えっと、あの、その、なんか、まあ、ていうか、やっぱ。年轻人「なんか」和「ていうか」高发，老人「まあ」「あのね」，职场「えーと」「そうですね」。
- 频率上限照 `../07-惯用词与口头禅.md`。

## 六、二次元里的句末

- 女性句末可以回来：轻度的角色用「〜わよ」「〜かしら」不算错，但要是这个角色的标记，不是全女性共用。
- 男性句末也可以回来：「〜だぜ」「〜だな」「〜ぞ」。
- 语尾是人物的招牌，每句都一样会变成噪音；照 `05` 的上限，让它出现在最需要的那句上。
- 同一个角色的语尾在对象不同时也可以变：主角「〜ぜ」，对老师「〜っす」。

---

## 七、不要把性别表现写成规定

现实里有用「僕」的女性，也有说「〜かな」的男大叔，有女性语的老派男性（おネエ言葉、オネエキャラ）。
- 档案写**这个人**，不写「女人怎么说」。
- 跨性别、同性恋角色不等于「女性语 / オネエ言葉」，后者是役割语，写实剧里默认不用，除非本人选择。
- 金水敏也指出，「女性语」本身就是一种约束人的规范。写实风格里让女性角色用什么句末，本身就是对人物的判断，不要默认为「女性＝柔和」。
