# 役割语和二次元

金水敏 2003 年提出「役割語」：一听就能想到特定人物形象的说话方式（词、语法、语调）。关键点：

- **现实里几乎没人这么说**，但日本人听到就懂。NINJAL 也这么解释：老爷爷的说法来自江户后期小说，大小姐的说法来自明治女学生。
- 所以它只属于**二次元、喜剧、年代虚构、儿童内容**。现实风格默认不用。
- 语法要对。役割语是有结构的，「拙者は行くですわ」是混搭。
- 定延利之把「〜にゃ」「〜ぴょん」这种放在普通句子末尾的成分叫キャラ助詞；金水叫キャラ語尾。一般用法：只加在平常的句末上，意思不变。

下面所有表都是**配方**。同一个类型的角色也要有个性，不要照抄到每句（上限见文末）。例句都是这里写的示意。

**黑帮、不良、热血少年、JK、刑事、チャラ男这些现实里也有原型的类型，有成套的称呼、词汇和规矩，看 `05a-经典角色语言体系.md`。**

## 一、现实 vs 二次元：同一个人设两种写法

| 人设 | 现实风格 | 二次元·重 |
|---|---|---|
| 大小姐 | 私；丁寧、美化语（お食事、お電話）；「そうですね」「ありがとうございます」；话慢、不说粗话。「〜ですわ」基本没有。部分女校有「ごきげんよう」的传统 | わたくし；それは違いますわ。よろしくてよ。ごきげんよう。 |
| 老人（东京） | 私、僕、俺；〜だよ、〜だね、〜ですよ、まあ、あのね；缩约少 | わし；それは違うのう。知っておるぞ。 |
| 老人（広島等） | わし、〜じゃ、〜けえ（**这是真方言**，写实剧也可以） | |
| 老教授 | 私、僕；〜ですね、〜だね；讲课「〜なんですよ」 | わし；そうじゃ、わしが発明したのじゃ。 |
| 不良高中生 | 俺、オレ；うるせえ、知らねえ、マジで、は？；比二次元话少 | 俺様；ぶっ飛ばすぞ、てめえ！ |
| 军人、自卫官 | 私、自分；標準敬语，「了解」「はい」 | 自分、本官；〜であります！ |
| 中年女性 | 私、あたし；〜よね、〜じゃない？，〜わよ（50 岁以上还有） | あたし；〜なのよぉ、ちょっとあんた！ |
| 武士（年代剧写实） | 需要时代考证，写〔待核〕 | 拙者；それは違うでござる。 |

## 三、用户最常问的几个词

| 词 | 读法、写法 | 谁对谁 | 错在哪 |
|---|---|---|---|
| おぬし | 写假名，汉字「お主」 | 老人、武士对同辈或下级 | 对上级不能用；现实不用 |
| そなた | 写假名 | 上位者对下位者，带点温柔、古风 | 不是敬语 |
| 汝 | **なんじ**，写假名防误读 | 神、魔王、古语的「你」 | 「汝は」 |
| 我 | **われ** | 魔王、神。用「我は」「我が〜」 | **関西、広島的「ワレ」是骂人的「你」** |
| 貴様 | きさま | 骂人；字面是敬语，实际是侮辱 | 想表达尊敬绝不能用 |
| わらわ | 写假名；汉字「妾」另读めかけ（小妾） | 公主、女王 | 汉字容易读错成 めかけ |
| 拙者 | せっしゃ | 武士，谦称 | **西式奇幻**骑士说就是日本味乱入 |
| 余 | よ | 帝王 | 单写容易读错：写假名或「余は」 |

## 四、大小姐语的语法（模型最容易错）

| 接在 | 对 | 错 |
|---|---|---|
| 名词 | 東京ですわ | 東京だですわ |
| 形容词 | 美しいですわ、美しいですこと | 美しいだわ |
| 动词 | 行きますわ、参りますわ | **行くですわ** |
| 过去 | 行きましたわ、そうでしたわ | 行ったですわ |
| 疑问 | そうですの？、よろしくて？、いかがかしら？ | |
| 否定 | 違いますわ、存じませんわ | 違うですわ |
| 感叹 | まあ、素敵ですこと | |
| 命令、请求 | お待ちになって、ご覧あそばせ | 待ちなさいですわ |

- 敬语要配套：说别人的动作用尊敬语（ご覧になって），说自己的用谦让语（存じませんわ）。
- 美化语多：お紅茶、お庭、お食事。
- 对同辈：「〜さん」或「〜様」；对仆人用常体：お茶をちょうだい。
- 近年网上有「ですわ構文」这种故意的玩笑（「〜ですわ〜！」），不要当成正统大小姐，它是搞笑款。
- 「〜てよ」「〜こと」现实已基本消失，只留在役割语里；〜の、〜わ 还留在普通的女性语里。

## 五、奇幻和古风的通用规矩

1. **定世界观的「和」或「洋」**。西式奇幻（骑士、王国）不用 ござる、候、殿（〜殿 可用作军官式敬称，但慎用）。写「参る」「いたす」就够古风。王用「〜ぬ」「〜せよ」就够了。
2. **现代词穿帮**：古风和奇幻里不说 じゃん、っす、マジ、ヤバい、OK、タイミング、させていただく。
3. **古语要一致**：不要把「〜でござる」和「〜っす」混用。
4. **同一个世界里，不是所有人都用役割语**：配角和旁人用普通说法，才显得特殊的人特殊。

## 六、频率上限（在 `../07-惯用词与口头禅.md` 基础上）

| 类型 | 上限 |
|---|---|
| ★★★★★（〜にゃ、〜でおじゃる） | 主角不用；配角一场 2–3 次，只放在收尾句 |
| ★★★★（〜でござる、わらわ） | 句句有这个人设的时候也要变化：〜でござる、〜でござろう、〜にござる、「かたじけない」混用；连续两句不用同一个结尾 |
| ★★★（〜ですわ、〜じゃ） | 一段 3 句里 1–2 句；其余用同系列的句末（〜ですの、〜かしら），或者干脆不用 |
| ★★（〜っす、〜だぜ） | 可以常用，但别每句都有 |

**一个角色只给一个夸张点。** 大小姐不要同时有猫耳语尾、中二台词和関西腔。喜剧除外，而且要明白是在搞笑。

**固有作品味太重的语尾**（一听就知道是哪部作品的）不用，除非明确要致敬，并说明借了什么。

## 七、不能随便用的

| 内容 | 问题 | 怎么办 |
|---|---|---|
| 「〜アル」「アイヤー」的中国人 | 有歧视历史 | 默认不用。外国人角色用停顿、英语和简单句 |
| 片假名怪腔的外国人（ワタシ、ニホンゴ、ワカリマセン） | 刻板 | 同上 |
| オネエ言葉 | 把性少数写成笑料 | 只有本人选择时才用，并给他和口音无关的目的 |
| 乡下话（おら、〜だべ） | 把地方写成土气 | 给他能力和目的（`../principles.md` 第三节） |
| 皇室用语（朕、陛下）指真实人物 | 敏感 | 架空世界可以；真实皇室别用 |
| 真实地区方言配反派、罪犯 | 刻板 | 想清楚，不默认 |
