# 敬语和内外

**敬语错了，日本观众第一个出戏**。这一页是语法，不是风格：现实风格必须对；二次元可以有不用敬语的角色，但用了就要对。

框架按文化审议会《敬語の指針》（2007）的五分类。

---

## 一、五种敬语

| 种类 | 抬谁、怎么抬 | 例 |
|---|---|---|
| 尊敬语 | 抬高**动作的主体**（对方或第三方做的事） | いらっしゃる、おっしゃる、ご覧になる、お読みになる |
| 谦让语 I | 降低我方，抬高**动作指向的人** | 伺う、申し上げる、拝見する、お届けする |
| 谦让语 II（丁重语） | 对**听话的人**郑重地说我方的事，不需要有被抬高的对象 | 参る、申す、いたす、おる |
| 丁宁语 | 对听话人礼貌 | です、ます、ございます |
| 美化语 | 说得优雅，不抬任何人 | お酒、お料理、ご飯 |

**伺う和参る的差别**：「社長のお宅に伺います」抬社长；「明日、北海道に参ります」只是对听话人郑重，北海道不需要被抬。「北海道に伺います」就错了。

## 二、常用动词表

| 意思 | 尊敬语（对方做） | 谦让语（我方做） |
|---|---|---|
| 在 | いらっしゃる、おいでになる | おる（II） |
| 去 | いらっしゃる、おいでになる | 伺う（I）、参る（II） |
| 来 | いらっしゃる、お見えになる、お越しになる | 伺う（I）、参る（II） |
| 说 | おっしゃる | 申し上げる（I）、申す（II） |

| 知道 | ご存じだ | 存じている（II）；知道某人：存じ上げる（I） |
| 想 | お思いになる | 存じる（II） |
| 听、问 | お聞きになる | 伺う、拝聴する（I） |
| 见面 | お会いになる | お目にかかる（I） |
| 给 | くださる（对方给我） | 差し上げる（我给对方） |
| 收到 | お受け取りになる | いただく、頂戴する、賜る（I） |
| 借 | お借りになる | 拝借する（I） |
| 穿 | お召しになる | |
| 睡 | お休みになる | |
| 死 | お亡くなりになる、亡くなる | 亡くなりました（说自家人时，「死にました」也有人用） |

能套的公式：尊敬语「お／ご〜になる」「〜（ら）れる」「お〜くださる」；谦让语「お／ご〜する」「お／ご〜いたす」「〜ていただく」。

敬体请求的梯度（越往下越客气，也越长）：

> 来てください → 来ていただけますか → お越しいただけますか → お越しいただけますでしょうか → お越しいただけますと幸いです（书面）

## 三、内外（ウチ・ソト）：决定抬谁

**听话的人是外人时，自家人不能抬高，哪怕是自己的老板或父母。**

| 场面 | 错 | 对 |
|---|---|---|
| 对客户说自家部长 | 田中部長はただいまいらっしゃいません。 | 部長の田中はただいま席を外しております。 |
| 对客户说自家部长的话 | 部長がおっしゃっていました。 | 田中が申しておりました。 |
| 公司内对同事说部长 | 部長が申しておりました。 | 部長がおっしゃっていました。 |
| 对老师说自己母亲 | お母さんがいらっしゃいます。 | 母が参ります。 |
| 接电话找人 | 鈴木さんはおりますか。（对方家的人用了谦让语） | 鈴木さんはいらっしゃいますか。 |

要点：

- 外部面前：自家人**不带さん、不带职务后缀**，职务放前面（部長の田中）。
- **内外跟着听话人变**：同一个部长，对同事是「外面的上级」，要敬；一到客户面前就变成「自家人」。一场戏里镜头切到不同对象，敬语也要切。
- 家里人对外同理。

- **听话人不会觉得该抬的第三者，不抬**：对朋友说自己高中的学长，「先輩がいらっしゃって」会怪，说「先輩が遊びに来たんですけど」（《敬語の指針》）。
- **对部长说课长**：《敬語の指針》承认两种做法都有道理：不抬课长（部长看来他不算上位），或者抬课长（顺带也抬了部长）。看三人的距离和场面，可以当作人物差异来写。

**检查方法**：每一句带敬语的话，都问两遍：动作是谁做的？听话人和被说到的人，是一家还是两家？

## 四、高频错误对照

| 错 | 原因 | 对 |
|---|---|---|
| おっしゃられる、ご覧になられる、お読みになられる | 二重敬语（尊敬 + れる） | おっしゃる、ご覧になる、お読みになる |
| 拝見されましたか | 谦让语配尊敬形 | ご覧になりましたか |
| 受付で伺ってください | 谦让语用在对方身上 | 受付でお尋ねください |
| 申されました、参られました | 谦让 II 配尊敬形 | おっしゃいました、いらっしゃいました |
| ご利用できません（对客户） | 「ご〜できる」是谦让形 | ご利用になれません |
| 召し上がられますか | 二重敬语 | 召し上がりますか |
| ご利用される、ご説明される（对对方的动作） | 《敬語の指針》：规范上不算合适的尊敬语，实际却很常见，所以写成「不太讲究」的人物可以 | ご利用になる、ご説明なさる |
| 部長さん（对自家部长） | 职务本身含敬 | 部長 |
| 社長様 | 同上；对外也多用「〇〇社長」，信封除外 | 社長 |

**不算错的二重形**（习惯上已经固定，《敬語の指針》承认）：お召し上がりになる、お見えになる、お伺いする、お伺いいたす。

**《敬語の指針》说可以接受的**：「とんでもございません」用来谦虚地回应夸奖，现在没有问题。**敬语不是越多越礼貌**：《敬語の指針》也特别提醒，堆得太多反而失礼、显得疏远。

「させていただく」：《敬語の指針》说，基本上用在**得到对方或第三者允许、我方因此受益**的时候。「コピーを取らせていただけますか」自然；「○○高校を卒業させていただきました」就不自然。「読まさせていただく」这种多了「さ」的说法（さ入れ）是常见的错，可用作设计。

## 五、不是语法、但现实很在意的（职场礼仪）

这些是礼仪常识，现实中有人遵守、有人不在意。**用来写人物**：会不会这些，说明他懂不懂规矩。

| 情况 | 稳妥 | 对上级显得轻或不太稳 |
|---|---|---|
| 同意、收到 | 承知しました、かしこまりました | 了解です、了解しました（同级和下级可以） |
| 打招呼、慰劳 | お疲れ様です（《敬語の指針》建议更郑重地说「お疲れ様でございました」） | 御苦労様です：《敬語の指針》说这是上对下，或者对为自己干活的人（如送货员） |
| 道歉 | 申し訳ございません | すみません（轻）、ごめんなさい（私下） |
| 附和 | おっしゃる通りです、そうですね | なるほどですね、なるほど |
| 请教 | 教えていただけますか | 教えてください（形式正确，较直接；对不熟的上级、客户选更缓的） |
| 拜托 | お願いできますでしょうか | やってください |

**缓冲语**（クッション言葉），现实里每次请求或拒绝前都有：恐れ入りますが、お手数ですが、あいにく、差し支えなければ、申し訳ございませんが。

**慣用的公司话**：お世話になっております（寒暄）、ご確認のほど（书面）、持ち帰って検討します（基本等于拒绝）。

## 六、错误也是设计（档案里写清楚）

| 类型 | 例 | 谁 |
|---|---|---|
| バイト敬語、コンビニ敬語 | 千円からお預かりします。こちらお弁当になります。よろしかったでしょうか。 | 年轻店员 |
| 用力过猛 | おっしゃられました。ご拝見いたしました。 | 新人、往上爬的人（`../03-语体与切换.md` 的矫枉过正） |
| 敬语不熟 | 敬体没问题，尊敬语、谦让语混用 | 刚进公司的大学生、不常接触客户的工人、外国人 |
| 礼貌的攻击（慇懃無礼） | 大変結構なご意見でございますね。 | 高手讽刺；客服压怒火；女主人对情敌 |
| 故意不用 | 对上级说常体 | 关系破裂的信号，或者不服 |
| 敬语当距离 | 吵架后妻子突然改用敬体：はい、分かりました。 | **很有戏**：日语里敬体一出来，常常就是关系变冷 |

错得设计过的地方，写进档案第 4 维的「会错在哪」，并在 `check-labels.md` 打 `EXCEPTION_OK`，不算出戏。

## 七、二次元里的敬语

- **魔王、皇帝**：不用敬语，用古语命令；下属对他用满格敬语。
- **执事、女仆**：满格，「〜でございます」「かしこまりました」，尊敬和谦让都要对。
- **大小姐**：对外人、长辈周到敬语，对仆人用常体（お茶をちょうだい）。`05` 有详表。
- **武士**：「〜でござる」本身是丁宁，对主君再用「御意」「はっ」「〜にございます」。
- **不良、热血主角**：对谁都不敬是人设，但遇到真正尊敬的老师变成「〜っす」，这个切换是加分项。
