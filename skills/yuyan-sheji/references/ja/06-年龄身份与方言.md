# 年龄、身份、职业和方言

现实风格的主要参考。二次元也可以用这里打底，再按 `05` 加。

---

## 一、年龄段

| 年龄 | 自称 | 语言特征 | 边界 |
|---|---|---|---|
| 幼儿 | 名字、ぼく、わたし | 句子短，〜の、〜だもん、ねえねえ、「あのね」；发音错不用谐音写 | 「でちゅ」是赤ちゃん言葉，是大人对幼儿说，孩子本人不说 |
| 小学 | 男：ぼく、おれ；女：わたし、名字、うち | 常体；〜じゃん；不会敬语，只会「です」「ます」 | 不说尊敬语 |
| 中学 | 男：俺、僕；女：うち、私、あたし | 开始有前后辈敬语，〜っす，流行语多 | |
| 高中 | 男：俺；女：うち、私、あたし | 缩约多，やば、まじ、〜くね？、〜じゃね？ | 敬语只有简单版 |
| 大学 | 男：俺、僕；女：私、あたし | 打工学了バイト敬語；就职活动时用力的敬语 | |
| 新人（22–26） | 私、僕 | 敬语紧张，容易过度：させていただきます、〜の方 | |
| 中坚（27–45） | 私、俺、僕 | 公司话熟练，切换快 | |
| 管理层（45–60） | 私、僕、俺 | 对下：〜だよね、〜じゃないの；老派「〜たまえ」只有极少数 | |
| 老人（65+） | 私、僕、俺；西日本わし | 缩约少，「〜でね」「〜ですよ」「まあ」，老派女性还有〜わよ、〜かしら；ら抜き少 | **东京老人默认不说〜じゃ、わし** |

## 二、代际（俚语有年份）

写之前先定角色生于哪一年、青春期是哪几年。下面是**大致**流行的时段，标〔待核〕。

| 时段 | 词 | 例 |
|---|---|---|
| 昭和后期 | ナウい、ダサい、チョベリバ（90 年代） | 现在说就是老或故意 |
| 2000s | KY、ググる、マジ卍（2010s） | |
| 2010s | エモい、草、ワンチャン、〜み | |
| 2020s | 〜しか勝たん、それな、ガチ、タイパ、推し | 变化很快，一个不当就穿帮 |

**俚语是最容易过时、最容易写坏的部分**。短视频要长期放的，宁可用「まじ」「やばい」这种稳定的。AIGC 视频不可能追上最新梗，除非明确要求。

## 三、身份和阶层

日本没有 U / non-U 这样明显的「阶层词表」，阶层主要看：

| 看点 | 上层、受过良好教育 | 基层 |
|---|---|---|
| 敬语 | 熟练、自然、不夸张 | 公式化，或者只用丁寧语；不会用的时候用「〜です」糊弄 |
| 美化语 | お食事、お電話、ご飯 | 飯、腹減った（男性） |
| 汉语词比例 | 高，但不炫 | 和语多，口语多 |
| 句子 | 说完整，缓冲语多，不直接否定 | 短，直接；语义靠现场 |
| 粗话 | 少 | 多，也看性别和地域 |
| 地域 | 山の手（东京西部）腔；下町（东京东部）有「〜ねえ」「ひ／し混同」，现实已淡 | |

**和语、汉语、外来语**（相当于英语的日耳曼词、拉丁词）：

| 和语（口语、平易） | 汉语（书面、正式、受教育） | 外来语（商务、时尚、年轻） |
|---|---|---|
| 考える | 検討する、考慮する | コンシダーする（夸张） |
| 決める | 決定する | フィックスする（职场） |
| 始める | 開始する | スタートする、キックオフ |
| 打ち合わせ | 会議 | ミーティング、MTG |
| 割り当てる | 配分する | アサインする |
| やり直す | 再検討する | リスケする（改期） |

**用错词也有日语版**：矫枉过正的人说「ご拝見」「お力添えさせていただきます」「役不足」（把自己说得太高的误用）、「確信犯」（误用）。

## 四、职业

| 职业 | 特征 | 例（现实） |
|---|---|---|
| 営業、接待 | 缓冲语、敬语满格；转身对同事马上切回 | いつもお世話になっております。 |
| 店员（便利店、餐馆） | バイト敬語 | ご注文は以上でよろしかったでしょうか。 |
| 高级服务业 | 敬语准确，不用バイト敬語 | かしこまりました。少々お待ちくださいませ。 |
| 医生 | 对患者敬体 + 通俗说明；「お大事に」；同事间术语 | お薬、出しておきますね。 |
| 律师 | 敬语、法律词、缓冲；「先生」 | その点は確認が必要です。 |
| 警察 | 公务腔；对嫌疑人常体（お前、おい） | 署までご同行願えますか。 |
| 教师 | 对学生常体；「はい、〜してください」 | はい、静かにー。 |
| 工匠、工厂 | 话少、常体；对客人勉强敬体 | こりゃダメだな。 |
| 运动部 | 〜っす、うっす；前辈的话绝对 | 了解っす！ |
| 官僚、政治家 | 「〜という認識でございます」「適切に対応してまいります」，不直接回答 | 必要な検討を進めてまいります。 |
| 记者、主播 | 标准语，书面词 | |
| 黑道 | 现实比电影安静；表面客气更吓人 | 兄さん、ちょっとええかな。 |
| 风俗、酒吧 | 名字 + さん；〜ちゃん；奉承 | 社長、今日はお早いんですね。 |

## 五、方言

**规矩**（和 `../principles.md` 第三节一致）：

1. **不用假名拼口音**。方言靠词和语法。
2. **断定、否定、理由三处都要对**：只把句末换成「〜やで」，其他还是东京话，就是エセ関西（假関西腔），日本人一听就出戏。这也是 cccskills charatone 提的一条。
3. 一个人不混地域。
4. 方言常在「素が出る」时才冒出来：工作时标准语，回家、喝醉、发火时切回来。
5. **设定写了地方出身，就不能因为怕错而整个删掉**。整段方言才需要母语者核；打底用最稳的几个标记（関西：ほんま、あかん、〜やん、〜へん、〜や），平时藏着，失控时漏出来。整句没把握的标〔待核〕。

| 地域 | 断定 | 否定 | 理由 | 其他 | 「明天不去，因为忙」 |
|---|---|---|---|---|---|
| 东京标准语 | 〜だ | 〜ない | 〜から | | 明日行かないよ、忙しいから。 |
| 大阪 | 〜や、〜やで、〜ねん | 〜へん、〜ん | 〜から、〜さかい（古） | めっちゃ、ほんま、あかん、なんでやねん | 明日行かへんわ、忙しいねん。 |
| 京都 | 〜や、〜どす（花街） | 〜ひん、〜へん | 〜から、〜さかい | 〜はる（敬意）、おいでやす；「どす」现实极少 | 明日よう行かへんわ、忙しいし。 |
| 広島 | 〜じゃ、〜じゃけえ | 〜ん | 〜けえ | ぶち（很）、〜とる | 明日行かん、忙しいけえ。 |
| 博多 | 〜ばい、〜たい、〜と | 〜ん | 〜けん | 〜と？（疑问）、なんしよーと | 明日行かんよ、忙しいけん。 |
| 东北 | 〜だ、〜だべ | 〜ね、〜ねえ | 〜がら | んだ（对） | 明日行がねえ、忙しいがら。 |
| 北海道 | 〜だべ、〜っしょ | 〜ない | 〜から | なまら（很） | 明日行かないっしょ、忙しいから。 |
| 名古屋 | 〜だがや、〜だで | 〜せん、〜ん | 〜で | でら（很） | 明日行かんて、忙しいで。 |
| 沖縄 | 〜さー、〜よー | 〜ない | 〜から | なんくるないさ | 明日行かないさー、忙しいから。 |

方言的句子由这份资料的作者（非母语者）整理，**交付前全部标〔待核〕**。関西腔是最常见的，也是日本观众最挑剔的；要拿不准，改成标准语更安全。

## 六、外语夹用（第 5 维）

| 人 | 夹什么 | 例 |
|---|---|---|
| 意识高い系（做作的商务人） | 片假名商务词 | アジェンダ、コミット、アサイン、エビデンス |
| 海归、外企 | 英语词，有时整句 | それ、ちょっと risky じゃない？ |
| 高学历老派 | 少量德语、法语词（アルバイト、ドクトル） | 〔待核〕 |
| 老人 | 少，外来语常发错、说成日语 | パソコンのソフトが、なんとかで…… |

**片假名发音**：日语里的英语词要按日语发音写片假名，给 TTS 时不写罗马字（`07`）。

## 七、句子（第 6 维）和用典（第 8 维）

- 说一半：〜けど……，〜から……（`03`）；老人和上司长句多，年轻人短句多。
- 老派、知识分子用四字熟语、ことわざ、和歌：「一期一会」「石の上にも三年」。不要满嘴都是。
- 年轻人用网络和动画梗。AIGC 里引用要避开固有作品的台词。
- 比喻来自行当（`../08-修辞与用典.md`）：寿司师傅说「握り」，棒球迷说「九回裏」。
