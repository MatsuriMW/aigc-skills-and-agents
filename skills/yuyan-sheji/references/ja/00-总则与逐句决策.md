# 日语模式总则（JA 模式必读）

中文和英文的台词，一个角色大致一种说法，随对象调档。日语不是：**人称、动词形态、句末都由「谁对谁、在什么场面、说到谁」决定**，同一个人对不同的人，语法都不一样。所以日语档案不能只写「他说话什么样」，要写成「他对谁怎么说」的矩阵，台词要逐句过决策。

目标只有一个：做日语 AIGC 视频时，角色说出来的话是对的。这里的「对」分两层：

- **语法和礼仪上对**：敬语方向、内外、人称不能错。这一层错了，日本观众一听就知道是机翻。
- **人物上对**：这个人、这个年纪、这个身份，对这个人，会不会这么说。

## 一、先定风格：现实还是二次元

这是日语模式最先定的开关，写进档案第一行。差别不在夸不夸张，而在**语言的来源**：现实风格模仿真实日本人的说话；二次元风格用的是**役割语**（金水敏提出）：现实里几乎没人这么说，但日本观众一听就知道是什么人。「わしは知っておるのじゃ」是老人，「わたくし、存じておりますわ」是大小姐。

| 风格 | 用在 | 人称和句末 | 役割语 | 敬语 |
|---|---|---|---|---|
| **现实** | 真人感短剧、都市、职场、家庭、纪实、广告 | 按 `01`、`03` 里标「现实」的用；省略多、口语缩约多 | 不用。只允许角色在戏里**故意**玩一下（开玩笑模仿、老人本来就是方言区） | 按 `02`，必须对；错误只能是设计过的错 |
| **二次元·轻** | 校园日常、恋爱、职场喜剧番 | 现实打底，人称和句末略强化（女生偶尔「〜わよ」、男生「〜だぜ」） | 一个角色最多一个标记，比如只有自称特殊（僕っ子）或只有一个语尾 | 同现实，人物可以天然失礼 |
| **二次元·重** | 异世界、奇幻、古风、中二、萌系、搞笑 | 按 `05` 的类型 | 整套用，おぬし、われ、わらわ、拙者、〜ですわ、〜でござる、〜にゃ 都在这里 | 可以是这个类型自己的一套（魔王不用敬语，执事满格），但选了就要一致 |

几条规矩：

1. **现实风格里出现役割语，是最大的穿帮**：写实短剧里一个老人说「わしは〜じゃ」，或者二十多岁的白领说「〜ですわ」「〜かしら」，观众立刻出戏。
2. **二次元也要守语法**：役割语是特定的语法形式，不是随便加个语尾。「行くですわ」不成立，要说「行きますわ」。
3. **同一部片子风格统一**：一部片定一个基准，单个角色可以高一档（普通人的世界里来了个魔王）；这种落差本身是设计，写进档案。
4. **黑帮、不良、热血少年、JK 这些经典类型**，现实和二次元都有，有整套体系，分三层写：见 `05a`。
5. **定时代**：现代、昭和、明治大正、江户、架空。年代剧里的说法不等于二次元古风，真要做写实时代剧，每一句都要标〔待核〕，或者请懂的人看。

## 二、日语的语言坐标

在 `../principles.md` 的坐标表上，加这几项：

| 坐标 | 要问的 | 为什么 |
|---|---|---|
| 风格 | 现实 / 二次元·轻 / 二次元·重 | 决定用哪一张表 |
| 性别表现 | 这个人的说话方式偏男性、偏女性还是中性？不等于生理性别 | 决定人称、句末；年轻人越来越中性（`03`） |
| 年龄段 | 幼儿、小学、中学、高中、大学、新人、中坚、管理层、退休 | 人称随年龄换；句末和俚语也换（`06`） |
| 身份和阶层 | 家境、学校、职业、地位；历史或架空世界里的身份（王、公家、武士、商人、农民） | 决定敬语熟不熟练、用不用美化语、役割语类型 |
| 所属的上下秩序 | 部活、公司、家族、军队、师徒、宫廷 | 日本的上下由**所属秩序**定，先輩比自己大一岁也要敬 |
| 地区 | 东京腔、関西、広島、博多、东北…… | 自称（わし、うち）和句末都会变（`06`） |

**这张表不能替代关系表**：档案还要列出这个角色戏里每个对话对象的「上下、亲疏、内外」（模板第三节）。

## 三、逐句决策：写每句台词前过这七步

| 步 | 问 | 决定什么 | 参考 |
|---|---|---|---|
| 1 | 什么场面？公（会议、客户、面试、法庭）还是私（家、酒局、两人） | 同一对象，场面不同，语体就不同 | |
| 2 | 对方和我：**上下**（年龄、职位、前后辈）、**亲疏**（熟不熟） | 敬体（です・ます）还是常体（タメ口） | `04` |
| 3 | 句子里提到的人是**内**还是**外**？现在听话的人是内还是外？ | 谁该抬高、谁不能抬高 | `02` |
| 4 | 这个动作是谁做的？ | 尊敬语（对方做）还是谦让语（我方做）；方向错是最严重的错 | `02` |
| 5 | 这句要不要说人称？ | 默认省。要说时查这个角色对这个人的人称表 | `01` |
| 6 | 句末用什么？ | 性别表现、年龄、地区、役割语 | `03`、`05`、`06` |
| 7 | 读音和长度对不对？ | 该标假名的标，拍数放不放得下这个镜头 | `07` |

## 四、模型写日语的常见病

中文语境下让模型写日语，或者从中文剧本翻译，几乎总会这样错。检查时先查这几条，脚本 `yuyan_tool.py ja` 能抓一部分。

| 病 | 例 | 改 |
|---|---|---|
| **所有人都用「〜だ。」说死**（AI 日语台词最典型的毛病，书面语和报告的口气；cccskills 的 charatone 指出的） | それは違う。俺が行く。問題ない。 | それは違うだろ。／ 違うと思うよ。／ 俺、行くよ。／ 大丈夫だって。「〜だ。」只留给决断的那一句 |
| 设定有地方出身，台词却全是东京话 | 大阪社长说得和东京白领一样 | 至少在失控时漏出来（`06` 第五节） |
| 人称太满（翻译腔） | 私はあなたが好きです。 | 好きです。／ 好きだ。（谁喜欢谁，场面已经说明了） |
| 对上级说「あなた」 | 部長、あなたはどう思いますか。 | 部長はどう思われますか。（用职务或名字，不用二人称代词） |
| 所有人都用敬体，或者所有人都用常体 | 朋友之间：今日は暑いですね。 | 今日あっつ。／ 暑いね。 |
| 句子太完整，没有口语缩约 | 何をしているのですか。 | 何してんの？ ／ 何してるんですか。 |
| 书面的「のだ」「である」进了口语 | 私は行くのだ。 | 行くんだ。／ 行くよ。 |
| 年轻女性满口女性句末 | 素敵だわ。行くのよ。いくらかしら。 | 素敵だね。行くの。いくらかな。（`03`） |
| 男性满口「だぜ」 | 行くぜ！ やるぜ！ | 现实里：行くよ。やるか。（`だぜ` 现实里已经接近玩笑） |
| 尊敬语、谦让语方向反 | 私がご覧になります。／ 部長が拝見しました。 | 私が拝見します。／ 部長がご覧になりました。 |
| 对外抬高自家人 | （对客户）田中部長はいらっしゃいません。 | 部長の田中は席を外しております。 |
| 二重敬语 | おっしゃられました ／ ご覧になられましたか | おっしゃいました ／ ご覧になりましたか |
| 「させていただく」泛滥 | 説明させていただかせていただきます。／ 三日休まさせていただきます。 | ご説明します。／ 三日お休みをいただきます。 |
| 直接拒绝、直接否定 | いいえ、できません。 | ちょっと難しいですね……。（语用，`04` 末尾） |
| 汉字混入简体字 | 这、说、时间的「时」 | 脚本可以扫：这、説、時 |
| 中文的「您」直译成敬语堆叠 | 全句尊敬语，动作却是自己做的 | 过第 4 步 |

## 五、十个维度在日语里怎么用

十个维度（`../维度索引.md`）不变，日语里它们的落点是：

| 维度 | 日语怎么落 | 读 |
|---|---|---|
| 1 地域 | 东京标准语、関西、広島、博多、东北；写语法和句末，不写谐音 | `06` |
| 2 社会方言和职业 | 体育会、ヤクザ、不良、JK、医者、店员；同一人设分真实、影视、漫画三层 | `05a`、`06`、`05` |
| 3 语体和切换 | **核心**：人称和句末都跟着对象变，写成矩阵 | `04` |
| 4 用词水平 | 和语、汉语、外来语的比例（相当于英语的日耳曼词和拉丁词）；敬语熟练度 | `06`、`02` |
| 5 外语夹用 | 片假名外来语、商务英语（アサイン、コミット）、高学历夹英文；老人少用 | `06` |
| 6 句子复杂度 | 言いさし（说一半）、句尾留白、连用「〜て」 | `06` |
| 7 惯用词 | あいづち、えっと、まじ、やばい、語尾；频率上限照用 `../07-惯用词与口头禅.md` | `03`、`05` |
| 8 修辞和用典 | 老派用四字熟语、ことわざ、和歌；年轻人用网络和动画梗 | `06` |
| 9 语用 | 含蓄拒绝、缓冲语、道歉先行、敬语当武器（慇懃無礼） | `02`、`04` |
| 10 情绪失控 | 敬体掉成常体或反过来；生气时敬语变冷；男性「ai→ee」音变（うるせえ） | `04` |

**每个日语角色必写的**：人称表、对象矩阵、句末、敬语熟练度、读音。

**句末是土台，不是个性的主角**：句末由年龄、身份、距离决定，好几个人都用「〜です」完全正常，不要为了区分给每个人硬加一个语尾，那样只会更假。把人分开的是：他先注意到什么、怎么反应（先道歉、先算账、先开玩笑）、什么话不说、人称和称呼、句子长短和先说什么。
