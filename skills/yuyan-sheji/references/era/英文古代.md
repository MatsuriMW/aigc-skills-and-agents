# 英文古代

英语观众对古装的默认：英音、少缩写、称呼严格。这是约定，不是历史。先定时期。

---

## 一、时期

| 时期 | 特征 | 写法 |
|---|---|---|
| **中世纪和奇幻**（骑士、王国） | 真实的中古英语没人听得懂，用现代英语 + 称呼 + 少缩写 | *My lord, the bridge has fallen.* |
| **莎士比亚时代**（1500–1650） | thou / you 分上下亲疏；-est、-eth 动词 | *Thou hast no right to speak so.* |
| **乔治、摄政**（1714–1837） | 客套严密，「Mr」「Miss」；讽刺藏在礼貌里 | *I daresay you are mistaken, Mr. Hale.* |
| **维多利亚**（1837–1901） | 更拘谨；委婉，阶层分明 | *I must beg you not to speak of it.* |
| **美国西部**（19 世纪后期） | *ain't*、*reckon*、*fixin' to*；〔通行〕 | *I reckon he ain't comin' back.* |
| **海盗** | 「Arr」是电影来的（1950 年迪士尼《金银岛》Robert Newton 带红的）；写实的话不用 | |

---

## 二、thou 的规矩（最容易错）

| 形式 | 用在 | 例 |
|---|---|---|
| thou | **主语** | *Thou art*、*thou hast*、*thou dost* |
| thee | **宾语** | *I love thee.*（不是 *thee is*） |
| thy / thine | 所有格：名词前通常用 thy；thine 常见于元音前和部分 h 开头的词，也可以单用（*it is thine*）；实际随时期和文本变化 | *thy hand*、*thine eyes* |
| ye | 复数（旧） | |

**thou 不是「更古雅的 you」**：常见于上对下、对亲近的人、对神，或者用来羞辱；下对上一般用 *you*。对地位高的人用 *thou*，多半显得亲昵、轻蔑或冒犯，很有戏。实际用法随年代和关系变化。

动词：第二人称单数 -est（*thou speakest*），第三人称 -eth（*he speaketh*，也可用 -s）。写错不如不写。**通行层建议干脆不用 thou，只留在誓词、祷告和羞辱的时候。**

*forsooth*、*prithee*、*methinks* 少用，一用就像文艺复兴市集的角色扮演（ye olde 腔）。

## 三、称呼（摄政和维多利亚）

- 贵族：*Your Grace*（公爵）、*my lord / my lady*；*Sir John*、*Lady Anne*。
- 绅士淑女：*Mr. Darcy*、*Mrs. Bennet*。**未婚长女：Miss Bennet；其他女儿：Miss Elizabeth。**
- **不叫名字**：非亲人、未订婚的男女之间不叫名；从姓改叫名是重大事件。男性朋友之间用姓（*Bingley*）。
- 仆人：*sir*、*ma'am*、*m'lord*；对仆人叫名（女仆）或姓（男仆、管家）。
- 夫妻在外人面前也可以互称 Mr. / Mrs.。

## 四、不同身份（通行）

| 身份 | 用词和句子 | 例 |
|---|---|---|
| 王 | 我们（royal *we*）；命令 | *We are not pleased.* |
| 贵族 | 长句、从句、法语词；讽刺 | *How very singular.* |
| 商人 | 谈钱直接；想往上爬时用力（矫枉过正） | *I am, as you might say, a man of means.* |
| 农民、仆人 | *aye*、*nay*、*master*；方言语法；短句 | *Aye, m'lord. Field's flooded.* |
| 士兵 | 军衔、*sir*、粗话 | |
| 强盗、盗贼 | 贼话（thieves' cant）不要太多，观众听不懂 | *Hand it over, or I'll open your throat.* |
| 僧侣 | *my son*、*Brother*；拉丁语短语（`../05-外语夹用.md`） | |

## 五、古今替换

| 现代 | 古代（通行） |
|---|---|
| Hi / Hello | Good day、Good morrow（莎士比亚时代） |
| Yes / No | Aye / Nay（底层、中世纪）；Indeed / I think not（上层） |
| OK | Very well、As you wish |
| Thanks | I am obliged to you |
| Sorry | I beg your pardon、Forgive me |
| You guys | Gentlemen、you all |
| Damn it | Damn、Zounds（旧）、By God、By Jove（较晚） |
| What? | I beg your pardon? |
