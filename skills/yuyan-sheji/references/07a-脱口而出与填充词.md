# 脱口而出的话和填充词（现代）

人物最真实的时候，是**没来得及想**的时候。模型写的台词太干净：每句都想好了才说，没有「卧槽」，没有「那个」，没有说错改口。这一页管两样让台词接近真人的东西：**不假思索时蹦出来的话**，和**想下一句时用来填空的词**。

只管现代。古代的感叹词在 `era/` 里写几个就够。

---

## 一、脱口而出的话（下意识反应）

### 为什么它重要

这是人退回**底层语码**的瞬间（`principles.md`）：平时再体面，吓一跳时冒出来的是出身、家乡、信仰。**这是最便宜的人物塑造**：一个词就交代了他从哪来。

三个用法：

1. **立人**：老太太被吓到说 *Oh my stars*，律师说 *Jesus Christ*，同一件事两个人。
2. **露馅**：装成上流的人一疼就说「他妈的」，装本地人的外国人惊吓时说母语。这是戏。
3. **弧光**：从不骂人的人第一次说 *fuck*，全场安静。

### 怎么决定一个人说什么

顺着问：

| 问 | 决定 |
|---|---|
| 哪里长大的？ | 国别、方言（*bloody hell*、卧槽、なんでやねん） |
| 多大？ | 代际（*gosh* vs *what the hell* vs *bruh*） |
| 信教吗？ | 英语影响最大（*Lord have mercy*、*Jesus*）；中文「阿弥陀佛」「主啊」；日语少 |
| 什么阶层和教育？ | 骂人的强度，委婉程度 |
| 什么场合、谁在场？ | 当着孩子、老板要**收**（见「收回去」） |
| 什么情绪、多强？ | 见下面的表 |

**同一个人按情绪分**：不要只写一个口头语。惊讶、愤怒、疼、害怕、恶心、狂喜、尴尬、坏了，各写一个（下面的模板）。

### 英文

| 人群 | 惊讶 | 愤怒、坏事 | 疼、吓一跳 |
|---|---|---|---|
| 英国，普通 | Bloody hell、Blimey（偏老）、Crikey（偏老）、You're joking | Bollocks、For fuck's sake、Oh for God's sake、Sod it | Ow、Fuck、Shit、Bugger |
| 英国上层，老派 | Good Lord、Good God、Goodness、Gosh、Golly（老） | Damn、Blast（老）、Oh, for heaven's sake | Ah、Damn |
| 美国，年轻 | No way、What the hell、Holy shit、Oh my god、OMG、Bruh | Fuck、Shit、Are you kidding me、Hell no | Fuck、Shit、Ow |
| 美国，中年 | Jesus、Oh my god、Holy cow、Wow、You've got to be kidding | Son of a bitch、Damn it、Goddamn it | Son of a— |
| 美国，老太太 | Oh my、Oh my goodness、Oh dear、Well I never、Good heavens、Heavens to Betsy（很老） | Oh, for Pete's sake、Oh, fiddlesticks、Land sakes（很老） | Oh！、Oh dear |
| 美国南方、基督徒 | Lord have mercy、Oh Lord、Bless your heart（**这句通常不是真祝福**）、Good gracious | Lord help me、Dadgum | Oh Lord |
| 美国口语（AAVE 说话人也常用，但**这些不是 AAVE 的标记**，AAVE 靠语法，见 `02`） | Damn、Yo、Oh hell nah、Boy、Man | Oh hell nah、Man、What the（族群蔑称的社群内部用法默认不写，见 `principles.md` 第三节） | Damn、Shit |

**收回去**（minced oaths，当着孩子、老板、在教会）：*Oh sh—sugar*、*fudge*、*shoot*、*darn*、*gosh darn*、*what the heck*、*son of a gun*。写「话到嘴边改口」比写脏话更有戏。

**短剧常用的一类：「这下坏了」**：完了、坏了、这下完了、糟了、要命了、完犊子了。不同的人说法不同，遇到坏消息的第一句写这个，不写完整的「这真是太糟糕了」。

**收回去**：卧……（看一眼孩子）我的天；我去；靠；你大爷的。委婉形（卧槽→我擦、握草、卧靠）是网络的文字形，**嘴上说的和字幕上写的不一样**。字幕和审核也要考虑：卧槽、他妈的这类，平台可能要消音或改字，交付时提醒。

（地域表里的词是常识整理，没有全面的语言学调查，标〔待核〕，写方言角色时再核。）

### 日语

日语骂人的词很少，**脱口词主要靠感叹和说话方式**。

| 人群 | 惊讶 | 愤怒、坏事 | 疼、吓一跳 |
|---|---|---|---|
| 年轻人 | え、えっ、うそ、まじ、やば、は？ | は？、最悪、くそ、ふざけんな（偏男）、うざ | いたっ、いった（写成「行った」会读错，念白版写 いたっ）、うわっ、きゃっ |
| 中年男性 | おお、なに、まさか、うそだろ | くそ、ちくしょう、なんだと、まいったな | いてっ、うっ |
| 中年女性 | ええ？、やだ、うそでしょ、あら | もう！、信じられない、やだもう | いたっ、きゃっ |
| 老人 | おや、まあ、あらまあ、あらあら、おやおや、なんと | やれやれ、まったく、けしからん（老男） | あいたた、いたたた |
| 関西 | えー、うそやん、ほんま？、なんやて | なんでやねん、あほか、ふざけんな | いたっ、いったぁ〔待核〕 |
| 体育会 | まじっすか、うおっ | くそっ | うっ |

坏了：やばい、しまった、まずい、終わった。

二次元叫法另有一套（ふええ、はわわ、なっ…！、くっ…！），算役割语，现实风格不用。

## 二、填充词（filler）

说话时用来填补停顿、争取思考时间的词。短剧放进去，台词立刻活了；模型几乎不写，所以要写进档案。

### 分类（功能决定位置）

| 类 | 功能 | 英文 | 中文 | 日语 | 放哪 |
|---|---|---|---|---|---|
| 纯填空 | 没词了 | um、uh、er（英） | 嗯、呃、啊、这个 | えっと、あの、ええと、その | 句首、卡住处 |
| 思考、缓冲 | 争取时间、缓和 | well、so、I mean、you know、like | 那个、就是、然后、怎么说呢、你知道吧 | なんか、まあ、ていうか、なんていうか | 句首、句中 |
| 模糊限制（hedge） | 不想说死 | sort of、kind of、I guess、maybe、a bit | 有点、差不多、算是、好像、可能吧 | ちょっと、なんか、みたいな、感じ、かな | 句中、句尾 |
| 强调（已虚化） | 用来加重 | literally、actually、basically、honestly、totally、like | 真的、其实、说实话、反正、简直 | まじで、ほんとに、やっぱ、普通に、めっちゃ | 句中 |
| 确认（tag） | 拉对方进来 | right?、you know?、innit（英）、eh（加）、yeah? | 对吧、是吧、你说呢、懂吧 | 〜ね、〜よね、〜じゃん、でしょ | 句尾 |
| 附和（听的人说） | 表示在听 | yeah、right、mm、uh-huh | 嗯嗯、对对对、是是是、哦 | うん、はい、そうそう、へえ | 对方说话时 |

### 谁用什么

| 人群 | 英文 | 中文 | 日语 |
|---|---|---|---|
| 青少年 | like（极高频）、literally、bro、lowkey、honestly、I can't | 就是、然后、真的、绝了、那啥 | なんか、まじで、ていうか、やばい |
| 二三十岁职场 | like、actually、basically、to be honest、I mean、you know | 就是、其实、那个、说实话、怎么说呢 | なんか、やっぱ、そうですね、えっと、ちょっと |
| 中年 | you know、I mean、sort of、you see | 这个、那个、怎么说呢、说白了 | まあ、あの、なんていうか |
| 老人 | well、you see、now、dear | 这个、你说、我跟你讲 | まあ、あのね、そうねえ、なんだ |
| 领导、讲话 | so、right、obviously、look | 这个这个、啊（句尾拖）、对吧、是不是 | ええ、まあ、その |
| 学者、律师 | so、in a sense、arguably、I would say | 某种意义上、这么说吧 | まあ、言うなれば |
| 英国 | sort of、I mean、you know、innit（青年）、like（青年）、mate、to be fair | | |
| 美国 | like、you know、I mean、right、dude、man | | |
| 东北 / 北京 | | 那啥（东北）；这个、您猜怎么着（北京）。南方各地按具体方言点写，呢、嘛、啦是句末语气词，不算 filler | |

研究有几个可信的点：

- **um 和 uh 分人**：在英语语料里，年轻人和女性偏 *um*，年长者和男性偏 *uh*（Tottie 2011；Liberman 在 Language Log 的分析）。德语、荷兰语也有类似的现象。
- 真实语料里受教育多的人填充词并不少（Tottie）。**不要把 filler 写成「没文化」的标记**：这是常见的错。
- *literally*、*like* 这类词最容易被用来嘲笑年轻人，写的时候**有来历和功能**，不是贴标签。

（「谁用什么」表是常识整理，给档案起草用；每个人要挑具体的词，不是照表抄。）

### 怎么写进台词

1. **每个人只有 1–3 个招牌 filler**，不要把上面全部撒上去。两个人的 filler 不同，就多了一个认人线索。
2. **放在他在想、在躲、在怕的地方**。胸有成竹时没有 filler；撒谎、尴尬、谈钱、表白时一下子多起来。
3. **情绪改变密度**：紧张多，暴怒少（只有脏话），冷酷的人几乎没有。
4. **改口和重启比 filler 本身更真**：*I — no, what I mean is*；我不是……算了；あ、いや、そうじゃなくて。
5. **老人、外国人、对上级说话，filler 不同**。同一个人对老板「那个……我想说」，对朋友「就是吧」。
6. **念出来再定**。

### 密度（按类型）

| 类型 | 大约密度 | 说明 |
|---|---|---|
| 写实短剧、都市、纪实感 | 3 句里 1–2 处 | 放进来显得真 |
| 喜剧、吐槽 | 看人 | filler 本身可以是笑点 |
| 类型片（悬疑、动作） | 关键台词不放 | 紧张时才出现 |
| 古装 | 少，用别的（这个、哼、唉） | 见 `era/` |
| 二次元 | 少（えっと 例外） | |
| 广告、口播 | 看要不要真人感 | |

这是**默认值**，比 `07-惯用词与口头禅.md` 的通用上限宽，写实短剧按这里。真人的密度更高，全照搬反而难听。

### 给视频和配音

- filler 也占时长：えっと 3 拍，um 约半秒。短镜头算进去（`ja/07`）。
- TTS 常把 filler 念得太清楚：*um* 像念单词。写得短、用省略号带出气口；试听后不自然就删。
- 视频模型的台词里，filler 不宜多，容易对不上口型。

## 三、常用表达（口头语）

除了 filler，每个人还有几句**习惯的开头、转折和收尾**。和口头禅一样要有来历和上限（`07`）。

| 功能 | 英文 | 中文 | 日语 |
|---|---|---|---|
| 开头抢话 | Look、Listen、Here's the thing | 你听我说、我跟你讲、不是我说你 | あのさ、ねえ、ちょっといい？ |
| 坦白 | Honestly、To be fair、I'm not gonna lie、No offense but | 讲真、说实话、说白了、不瞒你说 | 正直、ぶっちゃけ、ここだけの話 |
| 反驳 | Yeah but、I mean、Well actually | 不是、话不是这么说、那也不能 | いや、でも、ていうか |
| 总结 | At the end of the day、Basically、Long story short | 反正、总之、说到底 | 要するに、結局、とにかく |
| 放弃 | Whatever、Forget it、Never mind、It is what it is | 算了、行吧、随便、爱咋咋地 | もういいよ、まあいいや、別に |
| 同意 | Right、Exactly、Totally、For sure、Yeah nah（澳：不） | 对对对、可不是嘛、那可不、是这个理 | そうそう、それな、だよね、確かに |
| 敷衍 | Sure、Uh-huh、Mm | 嗯嗯、好好好、知道了知道了 | はいはい、うんうん |

## 四、写进档案

```

| 惊讶 | | | |
| 愤怒 | | | |
| 疼、吓一跳 | | | |
| 害怕 | | | |
| 恶心 | | | |
| 狂喜 | | | |
| 尴尬 | | | |
| 坏了 | | | |

### 填充词和口头语

- 招牌 filler（1–3 个）：
- 什么时候变多：
- 什么时候没有：
- 爱用的开头、转折、收尾：
```

没把握的留〔待定〕，写了几场之后回写。**这一节最适合从已写的台词里长出来**。

## 五、不要这样

- 脏话不是性格。只有脏话没有人。骂人的强度和第一次骂的时机更重要。
- 平台审核：脏话、宗教词、族群词，交付时列出来提醒用户。
- 蔑称：见 `principles.md` 第三节。
- 不要把某个人群写成只会说这些词（`STEREOTYPE`）。
- 年代和流行词：*bruh*、「绝了」都有保质期。
