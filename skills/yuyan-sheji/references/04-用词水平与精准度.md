# 4 用词水平和精准度（档案的重点）

**用词水平**：他知道哪些词、平时用哪一档的词。
**精准度**（articulate 的程度）：他能不能用一个准确的词说中他要说的东西，还是要绕、要凑、要用错。

两样都由教育、阅读量、阶层、职业决定，是一开口就暴露身份的地方。模型的默认值是「所有人都很 articulate，用词都在 B2–C1」：律师、修理工、十四岁小孩说出来一个档。这份文件就是把这个默认值拉开。

## 一、档位

### 英文：CEFR 或词频档

| 档 | 大致范围 | 一个人只用这一档时听起来像 |
|---|---|---|
| A1–A2 | 最常用的 1,000–2,000 词 | 小孩、刚学英语的人、刻意说得很简单的人 |
| B1 | 3,000 词左右 | 日常口语的大多数人 |
| B2 | 5,000 词左右 | 受过中等教育、读东西的人 |
| C1 | 8,000–10,000 词 | 大学教育、阅读量大、专业人士 |
| C2 / 低频词 | 10,000 词以后，加专业词和文学词 | 学者、律师、作家、上层精英（或者装的人） |

同一个意思的几档说法（档案里写「他用哪一档，哪一档他不会用」）：

| 意思 | 低 | 中 | 高 | 最高 / 文学 |
|---|---|---|---|---|
| 生气 | mad, pissed | upset, annoyed | irritated, frustrated | exasperated, incensed, livid |
| 说谎 | lie, make stuff up | mislead | misrepresent | dissemble, prevaricate |
| 帮 | help | help out | assist | facilitate |
| 开始 | start | get going | begin | commence |
| 很多 | a lot, tons | plenty | considerable | myriad |
| 明白 | get it | understand | grasp | apprehend |
| 坏 | bad | not great | poor | egregious |

### 中文：词的档

| 档 | 例 | 用的人 |
|---|---|---|
| 口语常用 | 弄、搞、整、好多、特别、那啥 | 所有人；只用这一档的偏基层、偏年轻 |
| 书面常用 | 处理、解决、大量、尤其、相关 | 受过中等以上教育 |
| 雅词、书面词进口语 | 予以、进行、鉴于、不妨、未免、颇 | 体制内、知识分子、刻意体面的人 |
| 文言、典故、成语密集 | 不亦乐乎、未雨绸缪、孺子可教、殊途同归 | 老派知识分子、爱掉书袋的人 |

**成语和四字格的密度**是中文里最好用的一个指标：一段话里有几个、是活用还是套话。

## 二、日耳曼词和拉丁词：一个反直觉的地方

英语里同一个意思常有一个短的日耳曼来源词（*ask, buy, help, end, start*）和一个长的拉丁 / 法语来源词（*inquire, purchase, assist, terminate, commence*）。

| 谁 | 倾向 |
|---|---|
| 工人阶级、小孩 | 几乎只用短词 |
| 官僚、公文、客服 | 拉丁词用得最多，名词化（*the utilization of …*） |
| **往上爬的中产** | 刻意用长词显得体面，最容易用错 |
| 学者、律师 | 拉丁词用得多，但用得准 |
| **真正的上层（英国老钱）** | **反而偏爱朴素的短词**，不需要用词证明身份；长词留给反讽 |

所以「用词越高级 = 阶层越高」只对一半。档案里写清楚他是哪一类：**用得多不等于用得准，用得少不等于不会。**

## 三、U 和 non-U：英国阶层的词

Alan Ross（1954）和 Nancy Mitford（1955）提出的「U（upper class）和 non-U」。很多 1950 年代的分别今天已经不用了（*wireless / radio*、*looking-glass / mirror*），但人类学家 Kate Fox 在 *Watching the English*（2004）里说，下面这七个词今天仍然是英国中上层用来识别「不是自己人」的信号：

| non-U（中下层，想显得体面） | U（上层） |
|---|---|
| *Pardon?* | *What?* / *Sorry?* |
| toilet | loo, lavatory |
| dinner（指午饭） | lunch |
| settee, couch | sofa |
| lounge | sitting room, drawing room |
| sweet, dessert | pudding |
| serviette | napkin |

其他常见的：*How do you do?*（U，对方也回 *How do you do?*）对 *Pleased to meet you*（non-U）；*supper*（家常晚饭，U）对 *tea*（北方和工人阶级把晚饭叫 tea）；上层成年人仍叫父母 *Mummy / Daddy*。

**有意思的是**：non-U 的词很多是法语来的或「更体面」的（*serviette*、*pardon*、*lounge*）。想往上走的人选了听起来更文雅的词，恰恰暴露了自己。写往上爬的英国角色，这是最好用的一招（`01a-英式角色.md` 第四节）。

## 四、精准度的几个看点

| 看点 | 精准度高 | 精准度低 |
|---|---|---|
| 名词 | 具体：*the transmission*、*the lease*、「变速箱」「租约」 | 泛指：*the thing*、*stuff*、「那个」「东西」 |
| 数量和程度 | 有数：*three times since March* | 模糊：*like a bunch of times*、「好多次」 |
| 区分近义词 | *I'm not angry, I'm disappointed.* | 一个 *mad* 管所有负面情绪 |
| 限定 | 该限定的地方限定：*in this case*、*mostly* | 要么说死、要么全是 *kind of* |
| 找不到词时 | 停一下，换个说法 | 用凑词顶上：*thingy*、*whatchamacallit*、*you know what I mean*、「那个什么」「就是那种」「你懂我意思吧」 |

精准度低**不等于说不清楚**：Labov 1969 年批评 Bernstein 时说明了，非标准变体的说话人推理一样严密。精准度低的人常常靠语气、手势、共同经验、具体的例子补上，这些就是要写进档案的东西。

## 五、用错词：有意为之的设计

| 类型 | 英文例 | 中文例 | 给谁用 |
|---|---|---|---|
| 音近词替换（malapropism，得名于谢里丹 1775 年《情敌》里的 Mrs Malaprop） | *for all intensive purposes*（intents and）、*pacifically*（specifically）、*escape goat*（scapegoat）、*nip it in the butt*（bud） | 「首当其冲」当「首先」用 | 想显得体面、读得少、或者小孩 |
| 词义用反 | *irregardless*、*literally* 当强调 | 「差强人意」当「不满意」；「七月流火」形容天热；「万人空巷」形容街上没人；「炙手可热」当「受欢迎」 | 读过一点、没细查的人；有些已被大众接受，看角色是不是较真的那种 |
| 矫枉过正 | *between you and I*；*whom* 用在主语位置；*Contact myself* | 该说「的」的地方说「之」 | 往上爬的人，正式场合 |
| 大词错搭 | *We need to utilize synergy to facilitate our paradigm.* | 「我们要赋能这个底层逻辑」 | 被行话同化的人；讽刺对象 |

**用错词是设计，不是事故。** 写进档案的「用词」一栏：他会错哪一类、在什么场合错（往往是越想表现越错）、有没有人纠正他、他什么反应。

## 六、Bernstein 的两种语码（用来写倾向，不是用来分高下）

| | 限制性语码 | 精致语码 |
|---|---|---|
| 依赖 | 在场的共同语境 | 把语境说出来 |
| 代词 | 多，常没有先行词（*He did it again.*） | 先交代人，再用代词 |
| 理由 | 不说，靠关系和权威（*Because I said so.*） | 说出来，带条件和例外（*If you do that, then …*） |
| 句子 | 短、并列 | 从句多 |
| 好处 | 快、亲、圈内人一听就懂 | 对陌生人也说得清 |

同一个人在不同场合两种都用：在家用限制性的，在工作里用精致的。写进切换表。

## 七、同一句意思，四个人（验收用例 1 的写法）

意思：「我不同意。」

| 角色 | 台词 | 拉开的地方 |
|---|---|---|
| 14 岁美国初中生 | *Bro, no. That's literally not true.* | A1 词、*literally* 当强调、称呼 *bro* |
| 底特律修理工（AAVE） | *Nah. That ain't how it went.* | *ain't*；拿经验反驳，不拿概念 |
| 纽约诉讼律师 | *That's not what the record shows.* | 不说「我」，说证据；短句、准 |
| 伦敦老钱 | *I'm not sure that's quite right.* | 轻描淡写，*quite* 收着；实际意思是「你完全错了」 |
| 往上爬的中层经理 | *With all due respect, I'd have to respectfully disagree with that statement.* | 礼貌词叠两遍，名词化，越用力越不像 |
