# 5 外语夹用：受过良好教育的人会顺嘴带一句外语

欧美受过良好教育的人，说话会时不时夹一句外语，最常见的是**法语和拉丁语**：开饭前一句 *Bon appétit*，举杯一句 *Santé*，下结论一句 *C'est la vie*，讽刺一句 *Quelle surprise*，引一句 *in vino veritas*。给一个高学历的欧美角色写台词，一句外语都没有，他就少了一层。

这一条在档案里是一个单独的维度：**夹不夹、夹哪种、在哪些场合夹、夹多少、用得准不准**。

---

## 一、为什么是法语和拉丁语

- **拉丁语**：英国的公学（public school）和文法学校长期把拉丁语当必修，牛津剑桥的古典学（Classics）读的就是拉丁语和希腊语；法律、医学、天主教会也用拉丁语。所以拉丁短语在英美是「读过书」的信号，在法律和学术里是职业用语。
- **法语**：几百年里是欧洲外交、宫廷、上流社会、烹饪和时尚的语言；英语本身吸收了大量法语。会几句法语是「见过世面」的信号。
- **德语**：哲学、心理学、音乐的语言。知识分子爱用（*Zeitgeist*、*Schadenfreude*、*Weltanschauung*）。
- **意大利语**：艺术、音乐、美食、生活方式（*sprezzatura*、*dolce far niente*、*sotto voce*）。
- **希腊语**：古典学背景的人会用 *hubris*、*kudos*、*hoi polloi*（较真的人会指出 *the hoi polloi* 多了一个冠词）。

## 三、谁会说、怎么说：外语也分阶层

**夹外语是阶层信号，往两个方向都是。** 同一句 *Bon appétit*，在一个人嘴里是见过世面，在另一个人嘴里是装。

| 类型 | 倾向 | 边界 |
|---|---|---|
| 英国老钱、牛剑出身 | 低频、随口、不解释、发音准；拉丁语多用来开玩笑和自嘲（把小事说得像史诗） | 一场戏最多一两处；**不会**用外语显示自己有文化，那是 non-U |
| 美国常春藤、东海岸精英 | 法语、拉丁语固定短语，偏职业（律师的拉丁语、学者的德语） | 不说英式上层的那套自嘲 |
| 律师 | 法律拉丁语是职业用语，不代表阶层 | 对外行说 *res judicata* 就是在压人 |
| 学者、作家 | 德语、法语的理论词，偶尔一句原文引用 | 爱解释，因为习惯了上课 |
| 活了几百年的、跨国长大的角色 | 会说那种语言，不只是短语；对不同的人切不同语言，用来调情或威胁 | 切换要有目的，不炫 |
| 欧洲大陆的人说英语 | 骂人、数数、叫亲人、情绪上来时退回母语 | 这是母语，不是装饰 |
| **往上爬的人、装的人** | 用得多、用在不该用的地方、发音错、意思错（*a la mode* 当「时髦」用、*expresso*）；爱用法语来的「体面词」（*serviette*） | 写成设计：谁看出来了、谁在笑他 |

### *Bon appétit* 这个例子

- 在美国和英语世界的大多数场合，开饭说 *Bon appétit* 是礼貌，各阶层都说。
- 但在一部分英国上层和法国老派资产阶级的讲究里，这句被认为不太得体：吃饭是不必提的事，把「胃口」挂嘴上显得俗。主人会说 *Do start*、*Please, go ahead*，或者什么都不说，自己先动刀叉〔待核：礼仪出处〕。
- 所以：**想显得有教养的中产说 *Bon appétit*，真正的老钱不说**。这一个细节就能把两个人拉开。用的时候，旁边要有一个能看出来的人，不然观众接收不到。

## 四、写法规则

1. **只用固定短语**，不整句外语。除非外语是他的母语，或者剧情要他说给听得懂的人听。
2. **频率上限**：一场戏 0–2 处，一集里同一个短语不重复（招牌句除外，招牌句一集最多一次）。
3. **放在仪式性的节点**：开饭、举杯、告别、下结论、讽刺、认错。放在信息句里（*The meeting is at three, comme d'habitude*）就是在炫。
4. **不解释、不翻译。** 真会的人不解释；解释了就是在教人或在炫。观众听不懂没关系，语气和场合会说明意思；需要时字幕给中文。
5. **用错是设计**：给装腔的人用错，并在档案里写谁会看出来。
6. **拼写和重音符号写对**，字幕外语用斜体。
7. **配音提醒**：法语、拉丁语的发音要在给配音的说明里标出来（这个 skill 不管配音参数，只在交付时提一句）。

## 五、中文的对应：高学历角色夹什么

| 类型 | 夹什么 | 边界 |
|---|---|---|
| 当代海归、外企、高校青年教师 | 英文概念词和固定搭配：*dilemma*、*paradigm*、*by the way*、*anyway*、*basically* | 夹的是中文说起来费劲的词；夹 *very*、*happy* 这类基础词是在演 |
| 民国留学生、老派知识分子 | 英、法、德文原词（「德先生、赛先生」那一代），文言夹白话 | 写年代剧时对一下年代 |
| 五六十年代留苏的一代 | 偶尔夹俄语词（「哈拉少」之类，作为年代符号） | 只给那一代人用，一部戏一两次〔待核：具体用词〕 |
| 老派中文系、爱掉书袋的人 | 文言和典故：「不亦乐乎」「孺子可教」「善哉」「此一时彼一时」 | 一场一两句；用多了变成说书 |
| 港台和海外华人 | 英文词嵌在中文句里，见 `02-社会方言与职业语域.md` | |

## 六、写进档案的格式

```
外语夹用：
- 夹不夹：夹 / 不夹 / 只在某种场合夹
- 语种：法语、拉丁语（为什么：牛津古典学）
- 场合：开饭不说 Bon appétit，说 Do start；举杯 Santé；认输 Touché；叹气 Plus ça change
- 频率上限：一场戏最多 2 处
- 准不准：准，发音准，从不解释
- 例句：Plus ça change. 〔推测〕
```
