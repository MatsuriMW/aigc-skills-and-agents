# 6 句子复杂度

用词定的是「他知道什么」，句子定的是「他怎么组织」。模型的默认句子是中等长度、语法完整、一句一个意思：所有人都像在写邮件。

---

## 看哪几样

| 指标 | 怎么量 | 例 |
|---|---|---|
| 平均句长 | 英文按词数，中文按字数；`scripts/yuyan_tool.py stats` 能算 | 十四岁小孩 5–9 词；诉讼律师在法庭上 4–8 词、写意见书 25 词以上 |
| 从句嵌套 | 一句里有几层 *that / which / because / if*；Hunt（1965）的 T 单位：一个主句加挂在它上面的从句，「每个 T 单位的从句数」越高越复杂 | 学者 2–3 层；修理工 0–1 层 |
| 并列还是从属 | 用 *and / and then / but / so*、「然后」「就」串，还是用 *because / although / which*、「虽然……但是」「之所以……是因为」嵌 | 小孩和讲故事的人爱用 *and then*；律师用 *notwithstanding* |
| 插入语 | 句中插一段解释或限定：*— and I say this as a friend —* | 学者、英国上层、爱表现的人 |
| 未说完就断 | 话说一半停住、换方向、让对方接 | 情绪、犹豫、被打断、不想说 |
| 碎片句 | 没有主语或谓语：*Told him. Twice.* | 简洁、强硬、累 |
| 连珠句 | 一口气不换句号：抱怨、兴奋、喝醉 | |
| 主语省略 | *Gonna head out.*、「走了啊」 | 随便语体 |
| 话题前置 | *That car, I ain't touching it.*、「那车，我不碰」 | 口语常见，AAVE、东北话都多 |

中文另外看：**流水句**（逗号一路串下去）、**关联词密度**、把字句和被字句、四字格（见 `04-用词水平与精准度.md`）。

---

## 写进档案的格式

```
句子复杂度：
- 倾向：平均 6–10 词；并列为主，靠 and、so 串；话题前置多
- 边界：不会用 which 引导的非限制性从句；不会一句话里两个 although
- 例外：讲到他的老本行（变速箱）时，句子变长、变准，能一口气讲清一个故障的来龙去脉
- 例句：That bus, the 34? Transmission's shot. Been shot since March.
```

---

## 几个提醒

- **短剧台词本来就短。** 复杂度在短台词里靠**结构**体现：律师的短句是精确的短句（*At nine. Alone. Correct?*），修理工的短句是省掉的短句（*Told him.*），小孩的短句是没组织好的短句（*Like, and then he just — whatever.*）。三种「短」不一样。
- **情绪会改变句长**，往哪边变因人而异，写在 `10-情绪失控.md`。
- 别让所有角色都说完整句。模型写的台词里，真人几乎从不说完整句。
