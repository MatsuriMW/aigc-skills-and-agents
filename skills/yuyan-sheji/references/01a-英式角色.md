# 1a 英式角色：口音之外，词也得是英国的

要一个有英国口音的英国绅士，只交代「英国口音」是不够的：配音能补口音，补不了词。他嘴里要是冒出 apartment、vacation、Mom、gotten，观众听到的是一个装英国腔的美国人。**英国角色的台词必须同时满足：英式词表、英式语法、英式语用，再加上他那个阶层的用词。**

通用的英美词表和语法在 `01-国别地域与口音.md`；阶层用词（U / non-U）在 `04-用词水平与精准度.md`；夹法语、拉丁语在 `05-外语夹用.md`。这份只讲怎么把它们合在一个英国人身上。

## 一、英国角色必过的四关

| 关 | 检查什么 | 穿帮的例子 → 改法 |
|---|---|---|
| 词表 | 一个美式叫法都不能有 | *my apartment* → *my flat*；*on vacation* → *on holiday*；*Mom* → *Mum*；*the check, please* → *the bill, please* |
| 语法 | *have got*、*shall*、集体名词复数、介词 | *Do you have a minute?* → *Have you got a minute?*；*on the weekend* → *at the weekend*；*I've gotten used to it* → *I've got used to it*（英式基本不用 gotten） |
| 语用 | 轻描淡写、反讽、*I'm afraid*、*sorry*、反意疑问句 | 美式直说 *That's terrible* → 英式 *That's not ideal*；美式 *I disagree* → 英式 *I'm not sure that's quite right* |
| 阶层 | 他那个阶层用哪套词 | 上层说 *What?* / *Sorry?*，不说 *Pardon?*；说 *loo*、*napkin*、*sofa*、*pudding*，不说 *toilet*、*serviette*、*settee*、*dessert* |

**拼写**：剧本按英式出时用 colour、realise、Mum；按美式市场统一拼写时只换词不换拼写，在档案里写清楚。

## 二、「英国绅士」的语言机制

「绅士」本身是一个伞形词，拆开是下面这几条。挑适合这个角色的 4–6 条写进档案，别全上。

| 机制 | 倾向 | 例 |
|---|---|---|
| **轻描淡写**（understatement） | 坏事往小了说，好事也往小了说；越严重越平静 | 刚被捅了一刀：*Bit of a nuisance, this.* 看到杰作：*Not bad at all.* |
| **礼貌包着刀** | 威胁、拒绝、羞辱都用最客气的句式，句子更完整、更慢 | *I'd hate for there to be any unpleasantness.* *Do forgive me, but you're standing on my foot. Again.* |
| **反讽和自嘲** | 字面意思和真实意思相反，不加提示，等对方自己听懂 | *Oh, splendid. Another committee.* |
| **程度词收着用** | *quite*（英式里常常是「还算」，不是「非常」）、*rather*、*a bit*、*slightly*、*hardly* | *I'm rather fond of her.*（= 我很爱她）*It's quite good.*（= 一般） |
| **固定的客气句式** | *I'm afraid …*、*I wonder if you might …*、*Would you mind terribly …*、*Do sit down*、*Do start*（请先吃） | *I'm afraid that won't be possible.* |
| **称呼语** | 看阶层和关系：*old boy / old chap*（老派上层，今天多半带自嘲或讽刺）、*my dear*、*darling*（上层和演艺圈不分男女）、*love*（北方、工人阶级、也可以居高临下）、*mate*（中下层，或刻意放下身段）、姓氏直呼 | 冷：直接叫姓 *Morrison.* 热：*Darling, you look ghastly.* |
| **夸张的褒贬词** | 上层的形容词是一套：*splendid*、*marvellous*、*delightful*、*lovely*、*ghastly*、*frightful*、*dreadful*、*tiresome*、*vulgar*（骂人最狠的一个） | *How perfectly ghastly.* |
| **见识当武器** | 引用、典故、外语短语顺手带出，不解释 | *Plus ça change.*（`05-外语夹用.md`） |
| **骂人的词** | *bloody*、*bloody hell*、*sod (it / off)*、*bugger*、*bollocks*、*arse*、*git*、*prat*；上层生气时反而可能一句脏话都不说，改成冷冰冰的完整句 | *Oh, sod off.* 或 *I think you should leave. Now.* |

**边界**（英国绅士通常不会这么说）：*awesome*（年轻人可以）、*gotten*、*you guys*、*Mom*、*for sure*、*super*（当副词）、*like* 当填充词、在正式场合说 *Pardon?*。

## 三、两个参考人物：Klaus 和 Lucifer

这两个人都是**英国人在美国的地盘上**：周围全是美式英语，他们的英式词、英式语用和更高一档的语域本身就是身份标记，一开口就和周围的人拉开。这是出海短剧写英国角色最好用的一招：**让语言替他宣布他不属于这里，而且他比这里的人「高」一点。**

> 下面写的是看剧的整体印象，归纳的是机制，不是台词摘录。具体哪一集、哪句原话，用之前对着剧核一遍，没核过的不要当原话引用（标〔待核〕）。

### Klaus Mikaelson（《吸血鬼日记》、衍生剧《初代吸血鬼》，Joseph Morgan 饰）

一千多岁的初代吸血鬼和狼人混血，家族里的私生子，会画画，活过很多个世纪，在美国南方小镇和新奥尔良横行。

| 机制 | 他怎么用 |
|---|---|
| 称呼当武器 | 对女人叫 *love*、*sweetheart*，调情和压人用同一个词；对男人叫 *mate*，越不友好叫得越亲热 |
| 礼貌包着威胁 | 越要动手，句子越完整、越客气、越慢；威胁常常写成邀请或建议 |
| 见识和年岁 | 顺手提他亲历过的年代、见过的画家和战争，把「我比你老、比你懂」放在句子里，不明说 |
| 英式骂词 | *bloody* 一类，生气时出来；最危险的时候反而不骂 |
| 反讽的赞美 | 用夸奖来羞辱：先夸，再落一句轻的 |
| 情绪崩的方向 | 被家人刺痛时，从冷静的长句一下变成短促的吼；平时的风度是压出来的 |

### Lucifer Morningstar（《路西法》，Tom Ellis 饰）

魔鬼本人，厌倦了地狱，在洛杉矶开夜店，给洛杉矶警局当顾问。

| 机制 | 他怎么用 |
|---|---|
| 固定称呼 | 对搭档不叫名字，叫职务 *Detective*；给不喜欢的人起带职务的外号。称呼本身就是关系 |
| 英式家常词 | 父母叫 *Mum*、*Dad*，*bloody hell* 挂在嘴边。上帝和魔鬼的家事用英国中产家庭的词说出来，这个反差就是笑点 |
| 夸张的上层褒义词 | *splendid*、*marvellous*、*delightful* 这一类，用得热情、甚至带表演性 |
| 直白到冒犯 | 设定上他不说谎，所以该绕的地方直说（欲望、性、别人的弱点），但用的是绅士的词和句式 |
| 把客套和比喻当真〔待核〕 | 别人随口一句客气话或比喻，他按字面接，制造错位 |
| 调情和双关 | 几乎每段对话都能拐到欲望上，用词体面、意思不体面 |

### 两个人的共同点和区别

| | Klaus | Lucifer |
|---|---|---|
| 共同 | 英式词表 + 上层语域 + 在美国的「外来者」位置；礼貌是工具；见识和年岁是底气 | 同左 |
| 温度 | 冷，压着，礼貌底下是威胁 | 热，外放，礼貌底下是玩世不恭 |
| 称呼 | *love*、*sweetheart*、*mate*：亲昵词用来压人 | *Detective* 这类职务称呼 + 外号：把人放进他的分类里 |
| 风险 | 写过头会变成反派模板 | 写过头会变成只会讲荤段子 |

### 怎么借

1. 先定你的角色更靠哪一边（冷压 / 热炫），借那一列的 3–4 条机制，写进档案的「语用习惯」「惯用词」。
2. 称呼语、褒贬词、骂词都写**频率上限**，例如「*love* 一场戏最多两次」。
3. 他的英式词表照第一节的四关过一遍。
4. 台词自己写，不复用剧里的原话。

## 四、英国上层的几种人，别混成一个

| 类型 | 用词特征 | 和「绅士」模板的区别 |
|---|---|---|
| 老钱、贵族 | U 词（loo、napkin、sofa、*What?*），用词反而朴素，不用大词装体面；轻描淡写到极致；拉丁语、法语是玩笑和自嘲 | 不炫，最不费劲 |
| 牛剑学者 | 精准、长句、插入语和限定语多；典故来自古典和文学；会纠正别人用词 | 炫的是知识，不是身份 |
| 退役军官 | 短句、命令式、军队俚语，*Right.*、*Carry on.*；情绪最少 | 绅士感来自纪律 |
| 伦敦金融城 | 美式商务词混进英式（*circle back*、*deliverables*），上层口音 + 新钱的东西 | 说明他的钱是新的 |
| 往上爬的中产 | non-U 的「体面词」（serviette、*Pardon?*、lounge），法语用得多且容易错 | 越想像绅士越不像：这正是可以用的戏 |

**同一个英国角色，压力下会退回出身**：往上爬的人喝醉或吓到时，北方口音的词和 *I was sat* 这类语法会冒出来。写进档案的「例外登记」。
