# 10 情绪失控时往哪个方向崩

平时的说话方式是人控制住的结果。失控的时候，控制松开，露出来的是底下那一层。**往哪个方向崩，比平时怎么说更能说明他是谁。**

---

## 几个方向

| 方向 | 怎么崩 | 典型的人 |
|---|---|---|
| 变短 | 只剩几个词、只剩名字、只剩脏话 | 大多数人；军人、修理工 |
| 变长 | 一口气不停，越说越快，越说越远 | 平时压着的人、委屈的人、焦虑的人 |
| 变正式 | 生气时反而用完整句、用敬语、叫全名，冷下来 | 英国上层、律师、Klaus 那一类 |
| 口音变浓 | 退回方言、退回出身的那套 | 往上爬的人、离乡的人 |
| 口音变淡 / 变标准 | 越生气越字正腔圆，像念公文 | 在体制里的人、想压人的人 |
| 语码转换 | 骂人、哭、求人时切回母语 | 双语的人 |
| 精准度掉下来 | 找不到词，*thing*、「那个那个」，句子说一半 | 平时很 articulate 的人：这一下特别有冲击力 |
| 精准度反而上去 | 每个字都挑过，像在法庭上 | 律师、学者 |
| 重复 | 同一句话说三遍 | 震惊、崩溃 |
| 沉默 | 不说了 | 最危险的那种 |
| 笑 | 不合时宜地笑 | 撑不住的人 |

---

## 按处境写

| 处境 | 写什么 |
|---|---|
| 生气 | 方向 + 骂人的词换不换档 + 第一个变的是什么（称呼？句长？口音？） |
| 害怕 | 话变多还是变少；会不会变得特别有礼貌（求生的礼貌） |
| 悲伤 | 能不能说出那个词（「死」「走了」「没了」）；用什么代替 |
| 喝醉 | 平时藏的东西哪一样先出来：口音、脏话、真话、旧称呼 |
| 求人 | 放不放得下身段；放下时用什么词 |
| 在权威面前（法庭、警察、老板、长辈） | 往上切还是硬顶 |

这些处境里说的不像他的话，写进档案的「例外登记」：处境 → 破了哪条 → 怎么说。

---

## 写进档案的格式

```
情绪失控：
- 生气：变正式，叫全名，句子变完整、变慢；一个脏字都没有。第一个变的是称呼（love → 全名）
- 害怕：不会害怕（他自己这么认为）；真怕的时候话变多，开始讲道理〔待定〕
- 喝醉：北方口音出来，I was sat；叫母亲 Mam 而不是 Mother 〔推测〕
```
