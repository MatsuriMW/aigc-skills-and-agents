# 检查标签

模式 C 检查台词时，每一句打一个（或几个）标签，再给改法。标签借自 dropbars 博客里校准文风 skill 的做法（TOO_FORMAL、TOO_CASUAL、WRONG_WORD），按角色语言的需要扩了。

| 标签 | 意思 | 对应档案的维度 | 常见改法 |
|---|---|---|---|
| `OK` | 像他 | | 不动 |
| `GENERIC` | 换谁说都一样：客服腔、模型腔 | 全部 | 回档案，挑 2–3 个维度落词（用词档、句长、称呼、语用） |
| `TOO_FORMAL` | 比他在这个对象面前该用的语体高 | 3 语体 | 降一档：缩写、省主语、换短词 |
| `TOO_CASUAL` | 比该用的语体低 | 3 语体 | 升一档 |
| `TOO_ARTICULATE` | 用词比他的档位准、比他的档位高 | 4 用词 | 换成他会用的词，或让他找不到词 |
| `UNDER_ARTICULATE` | 用词比他的档位低、比他该有的模糊 | 4 用词 | 换成准确的名词 |
| `WRONG_WORD` | 档案「边界」里写了他不会用的词 | 4 用词 | 换 |
| `WRONG_VARIETY` | 变体穿帮：英国人说 *apartment*，澳洲人说 *gas station* | 1 地域 | 查 `01-国别地域与口音.md` 的词表；`scripts/yuyan_tool.py variety` 可以先扫一遍 |
| `WRONG_FOREIGN` | 外语夹用不对：不该夹的人夹了、夹多了、拼错、位置不对 | 5 外语 | 查 `05-外语夹用.md` |
| `SYNTAX` | 句长、嵌套和档案对不上 | 6 句子 | |
| `TIC_OVERUSE` | 口头禅、称呼、填充词超了上限 | 7 惯用词 | 删到上限内，留在最需要的那句 |
| `WRONG_ALLUSION` | 典故或比喻的来源不对（修理工引莎士比亚） | 8 用典 | 换成他那个领域的 |
| `PRAGMATICS` | 请求、拒绝、道歉的方式不像他 | 9 语用 | |
| `EMOTION_DIRECTION` | 情绪上来时崩的方向和档案相反 | 10 情绪 | |
| `EYE_DIALECT` | 用拼错字模拟口音 | 原则 | 改回正常拼写，口音用词和语法表现 |
| `STEREOTYPE` | 只堆俚语、拿口音当笑料、方言角色只负责好笑 | 原则 | 删俚语，加语法规则；给角色一个和口音无关的目的 |
| `ANACHRONISM` | 年代不对的词：九十年代的人说 *rizz*，民国的人说「内卷」 | 年龄、代际 | 换成那个年份的 |
| `EXCEPTION_OK` | 不像他，但属于档案「例外登记」里的处境 | 例外 | 不动；如果是新的例外，登记进档案 |
| `NEW_HABIT` | 写得特别对，而且里面有档案没写到的习惯 | 回写 | 归纳成一条新规则补进档案，标〔台词〕和出处 |

一句可以打多个标签，例：`TOO_ARTICULATE` + `WRONG_VARIETY`。
