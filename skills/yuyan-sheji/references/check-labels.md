# 检查标签

模式 C 检查台词时，每一句打一个（或几个）标签，再给改法。标签借自 dropbars 博客里校准文风 skill 的做法（TOO_FORMAL、TOO_CASUAL、WRONG_WORD），按角色语言的需要扩了。

| 标签 | 意思 | 对应档案的维度 | 常见改法 |
|---|---|---|---|
| `OK` | 像他 | | 不动 |
| `GENERIC` | 换谁说都一样：客服腔、模型腔 | 全部 | 回档案，挑 2–3 个维度落词（用词档、句长、称呼、语用） |
| `TOO_FORMAL` | 比他在这个对象面前该用的语体高 | 3 语体 | 降一档：缩写、省主语、换短词 |
| `TOO_CASUAL` | 比该用的语体低 | 3 语体 | 升一档 |
| `TOO_ARTICULATE` | 用词比他的档位准、比他的档位高 | 4 用词 | 换成他会用的词，或让他找不到词 |
| `UNDER_ARTICULATE` | 用词比他的档位低、比他该有的模糊 | 4 用词 | 换成准确的名词 |
| `WRONG_WORD` | 档案「边界」里写了他不会用的词 | 4 用词 | 换 |
| `WRONG_VARIETY` | 变体穿帮：英国人说 *apartment*，澳洲人说 *gas station* | 1 地域 | 查 `01-国别地域与口音.md` 的词表；`scripts/yuyan_tool.py variety` 可以先扫一遍 |
| `WRONG_FOREIGN` | 外语夹用不对：不该夹的人夹了、夹多了、拼错、位置不对 | 5 外语 | 查 `05-外语夹用.md` |
| `SYNTAX` | 句长、嵌套和档案对不上 | 6 句子 | |
| `TIC_OVERUSE` | 口头禅、称呼、填充词超了上限 | 7 惯用词 | 删到上限内，留在最需要的那句 |
| `WRONG_ALLUSION` | 典故或比喻的来源不对（修理工引莎士比亚） | 8 用典 | 换成他那个领域的 |
| `PRAGMATICS` | 请求、拒绝、道歉的方式不像他 | 9 语用 | |
| `EMOTION_DIRECTION` | 情绪上来时崩的方向和档案相反 | 10 情绪 | |
| `EYE_DIALECT` | 用拼错字模拟口音 | 原则 | 改回正常拼写，口音用词和语法表现 |
| `STEREOTYPE` | 只堆俚语、拿口音当笑料、方言角色只负责好笑 | 原则 | 删俚语，加语法规则；给角色一个和口音无关的目的 |
| `ANACHRONISM` | 年代不对的词：九十年代的人说 *rizz*，民国的人说「内卷」 | 年龄、代际 | 换成那个年份的 |
| `EXCEPTION_OK` | 不像他，但属于档案「例外登记」里的处境 | 例外 | 不动；如果是新的例外，登记进档案 |
| `NEW_HABIT` | 写得特别对，而且里面有档案没写到的习惯 | 回写 | 归纳成一条新规则补进档案，标〔台词〕和出处 |

| `TOO_CLEAN` | 太干净：真人这时不会说这么完整、这么顺 | 7、6 | 加半句、改口、filler、脱口词（`剧本拷打.md`） |
| `NO_REFLEX` | 听到大事没有下意识反应，直接说内容 | 7 | 先写第一个字（`07a`） |
| `INFO_DUMP` | 说给观众听：两个人都知道的事 | 语用 | 删或改成争吵的前提 |
| `ON_THE_NOSE` | 直接说感受或主题，真人不会这么说 | 语用 | 换成做事、岔开、说反话 |
| `ERA_ANACHRONISM` | 古代台词里的现代词、时间单位 | 时代 | `era/` 的替换表，脚本 `era` |
| `ERA_ADDRESS` | 称谓不对身份、朝代或对象 | 时代 | `era/` 的身份表 |
| `ERA_MODERN_MIND` | 现代想法换了古代腔（古代王侯说职场话、深闺小姐谈现代恋爱观） | 时代 | 回这个身份真正会想什么 |

一句可以打多个标签，例：`TOO_ARTICULATE` + `WRONG_VARIETY`。

## 日语专用

通用标签照用（`TIC_OVERUSE`、`TOO_FORMAL` 等）。日语多下面这些，按严重程度从高到低。

| 标签 | 意思 | 查 | 改法 |
|---|---|---|---|
| `JA_KEIGO_DIR` | 尊敬语和谦让语方向反 | `ja/02` | 问「谁做的」 |
| `JA_UCHISOTO` | 内外错：对外抬高自家人，或者没抬对方 | `ja/02` 第三节 | 看听话人是谁 |
| `JA_DOUBLE` | 二重敬语（习惯上固定的除外） | `ja/02` 第四节 | 去掉一层 |
| `JA_PRONOUN` | 人称不对这个对象（对上级说あなた、俺） | `ja/01`、档案人称表 | 用职务或省略 |
| `JA_PRO_DROP` | 人称太满（翻译腔） | `ja/00` | 省 |
| `JA_REGISTER` | 敬体、常体用错对象，或一段话里无理由混用 | `ja/04` | 查矩阵 |
| `JA_GENDER` | 句末的性别不对这个人（年轻女性满口〜わ） | `ja/03` | 换中性句末 |
| `JA_DANTEI` | 「〜だ。」说死，像报告（不是刻意的） | `ja/03` | 加句末词或留白 |
| `JA_STIFF` | 该缩约没缩、句子太完整、のだ、である | `ja/03` 第三节 | 缩约 |
| `JA_ROLE_LEAK` | 现实风格里漏了役割语（东京老人说わし、白领说ですわ） | `ja/05` | 用现实版 |
| `JA_ROLE_GRAMMAR` | 役割语语法错（行くですわ） | `ja/05` 第四节 | 查语法 |
| `JA_ROLE_MIX` | 一个人混了不同类型，或西式奇幻说ござる | `ja/05` | 选一个 |
| `JA_LAYER` | 经典类型的层错了（现实短剧里说漫画层的黑帮话、动画腔的 JK） | `ja/05a` | 降一层 |
| `JA_DATED` | 俚语年份不对（2026 的高中生说夜露死苦、ぴえん；屏幕文字被念出来） | `ja/05a` | 换成稳定的口语 |
| `JA_ANACHRONISM` | 古风或奇幻里出现现代词 | `ja/05` 第五节 | 换 |
| `JA_FAKE_DIALECT` | 只换句末的假方言，或者地域混了 | `ja/06` 第五节 | 断定、否定、理由一起改，或者改回标准语 |
| `JA_READING` | 读音会错、没标 | `ja/07` | 标假名，念白版写假名 |
| `JA_SCRIPT` | 简体字混入、中日同形词用错 | `ja/07` 第四节 | 改 |
| `JA_LENGTH` | 拍数放不下这个镜头 | `ja/07` 第二节 | 换短敬语、拆镜头 |
